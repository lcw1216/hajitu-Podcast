# 德州扑克 数据结构与格式

---

## 附录：卡片数值编码

Python 与 C++ 之间传递牌数据时使用统一的整数编码，避免字符串转换歧义。

### 点数映射

| 点数 | 编码 | 点数 | 编码 |
|------|------|------|------|
| 2 | 0 | 9 | 7 |
| 3 | 1 | 10 | 8 |
| 4 | 2 | J | 9 |
| 5 | 3 | Q | 10 |
| 6 | 4 | K | 11 |
| 7 | 5 | A | 12 |
| 8 | 6 | | |

### 花色映射

| 花色 | 编码 |
|------|------|
| ♠ (spade) | 0 |
| ♥ (heart) | 1 |
| ♦ (diamond) | 2 |
| ♣ (club) | 3 |

### 整牌编码公式

```
card_id = rank * 4 + suit    // 范围 0~51
```

**解码：**
```
rank = card_id / 4
suit = card_id % 4
```

### 编码 ↔ 显示转换

Python 端提供转换函数（放在 `deck.py`）：

```python
RANK_MAP  = {0:"2",1:"3",2:"4",3:"5",4:"6",5:"7",6:"8",7:"9",8:"10",9:"J",10:"Q",11:"K",12:"A"}
SUIT_MAP  = {0:"♠",1:"♥",2:"♦",3:"♣"}
RANK_REV  = {v:k for k,v in RANK_MAP.items()}
SUIT_REV  = {v:k for k,v in SUIT_MAP.items()}

def card_id_to_json(card_id: int) -> dict:
    """0~51 → {"suit":"♠","rank":"A"}"""
    return {"suit": SUIT_MAP[card_id % 4], "rank": RANK_MAP[card_id // 4]}

def json_to_card_id(card: dict) -> int:
    """{"suit":"♠","rank":"A"} → 0~51"""
    return RANK_REV[card["rank"]] * 4 + SUIT_REV[card["suit"]]
```

## 1. Card（一张牌）

```json
{
  "suit": "♠",
  "rank": "A"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `suit` | string | 花色：`"♠"` `"♥"` `"♦"` `"♣"` |
| `rank` | string | 点数：`"2"`~`"10"` `"J"` `"Q"` `"K"` `"A"` |

### 约束

- `suit` 只能是四种字符之一，`rank` 只能是 13 种之一。
- 一副牌 52 张无重复，后端发牌时必须保证同一张牌不会发给两个玩家或同时出现在手牌和公共牌中。
- 手牌 `hand` 长度：preflop~showdown 阶段固定为 **2**；idle 阶段为空数组 `[]`。
- 公共牌 `communityCards` 长度随 phase 变化：

| phase | communityCards 长度 |
|-------|---------------------|
| idle | 0 |
| preflop | 0 |
| flop | 3 |
| turn | 4 |
| river | 5 |
| showdown | 5 |

## 2. Player（玩家）

```json
{
  "id": 1,
  "name": "玩家1",
  "chips": 1000,
  "currentBet": 0,
  "hand": [
    { "suit": "♥", "rank": "10" },
    { "suit": "♣", "rank": "J" }
  ],
  "action": "call",
  "state": "active",
  "isCurrent": true
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 玩家编号 1~8 |
| `name` | string | 显示名称 |
| `chips` | int | 剩余筹码，≥0 |
| `currentBet` | int | 当局已下注金额，≥0 |
| `hand` | Card[] | 手牌（preflop~showdown 为 2 张，idle 为空） |
| `action` | string | 当前动作 |
| `state` | string | 玩家状态 |
| `isCurrent` | bool | 是否当前行动玩家 |

### `action` 有效值

| 值 | 含义 |
|----|------|
| `""` | 等待行动或尚未行动 |
| `"fold"` | 弃牌 |
| `"check"` | 让牌（当前轮无人下注时可用） |
| `"call"` | 跟注 |
| `"raise"` | 加注 |

### `state` 有效值

| 值 | 含义 | 约束 |
|----|------|------|
| `"active"` | 未弃牌且未出局 | `chips ≥ 0` |
| `"folded"` | 本局已弃牌 | 不再参与本轮行动和下注 |
| `"out"` | 筹码为 0 已淘汰 | `chips == 0`，不参与后续任何局 |

### 约束

- `currentBet ≤ chips` 且非负。
- `state == "out"` 时 `chips` 必为 0，`hand` 为空。
- `isCurrent` 同一时刻**只有一个**玩家为 `true`。
- 每局开始前，`state == "out"` 的玩家不参与发牌和行动。

## 3. GameState（游戏全局状态）

```json
{
  "phase": "preflop",
  "communityCards": [
    { "suit": "♠", "rank": "A" },
    { "suit": "♦", "rank": "K" }
  ],
  "players": [ /* Player[] ×8 */ ],
  "pot": 200,
  "currentBet": 20,
  "dealerIndex": 0,
  "currentPlayerIndex": 3,
  "minRaise": 20
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `phase` | string | 阶段 |
| `communityCards` | Card[] | 公共牌 0~5 张 |
| `players` | Player[] | 8 个玩家 |
| `pot` | int | 总底池（所有玩家已下筹码之和） |
| `currentBet` | int | 当前轮（street）要跟注的金额，非总底池 |
| `dealerIndex` | int | 庄家位置 0~7 |
| `currentPlayerIndex` | int | 当前行动玩家索引 0~7 |
| `minRaise` | int | 最小加注额 |

### `phase` 有效值

| 值 | 含义 |
|----|------|
| `"idle"` | 等待开始 |
| `"preflop"` | 已发手牌，第一轮下注 |
| `"flop"` | 已发 3 张公共牌，第二轮下注 |
| `"turn"` | 已发第 4 张公共牌，第三轮下注 |
| `"river"` | 已发第 5 张公共牌，第四轮下注 |
| `"showdown"` | 摊牌比牌，分配底池 |

### 约束

- `communityCards` 长度必须与 phase 匹配（见 §1 表格）。
- `currentBet` 是当前 street 内要跟注的金额（即当前轮最高下注额），每进入新 phase 重置为 0。
- `pot` 包含所有玩家在本局已下的筹码总和。
- `minRaise` 最小值 = 大盲注；若已有加注，则 = 上一个加注额。
- `dealerIndex` 每局结束后轮换到下一位 `state != "out"` 的玩家。

## 4. 通信消息类型（完整枚举）

所有消息均为 JSON，通过 WebSocket 文本帧传输。

### 4.1 前端 → 后端

#### `join` — 玩家加入

```json
{
  "type": "join",
  "data": {
    "seat": 1,
    "name": "小明"
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `seat` | int | 座位号 1~8 |
| `name` | string | 自定义用户名，1~12 个字符（可选，默认 "玩家{seat}"） |

**约束：**
- `name` 为可选字段。不传或为空时，后端使用默认名称 `"玩家{seat}"`。
- 传入时自动去除首尾空格，超过 12 字符自动截断。
- 名称跨局保持，`reset_for_new_hand()` 不会重置名称。

#### `start_game` — 开始一局

```json
{
  "type": "start_game"
}
```

无 data 字段。仅当 ≥2 名玩家 `state != "out"` 时有效。

#### `player_action` — 玩家操作

```json
{
  "type": "player_action",
  "data": {
    "action": "raise",
    "amount": 50
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `action` | string | `"fold"` `"check"` `"call"` `"raise"` |
| `amount` | int | 仅 `raise` 时需要，必须 ≥ `minRaise` 且 ≤ 玩家 `chips` |

**各 action 的 amount 规则：**

| action | amount |
|--------|--------|
| `fold` | 无此字段或为 0 |
| `check` | 无此字段或为 0 |
| `call` | 无此字段或为 0（后端自动计算跟注额） |
| `raise` | 必须 ≥ `minRaise` 且 ≤ 玩家 `chips` |

---

### 4.2 后端 → 前端

#### `game_state` — 游戏状态全量同步

```json
{
  "type": "game_state",
  "data": { /* GameState 完整数据 */ }
}
```

每次状态变化后广播给所有连接的客户端。

#### `hand_result` — 摊牌结果

```json
{
  "type": "hand_result",
  "data": {
    "winners": [
      {
        "playerId": 1,
        "handName": "同花",
        "handRank": 5,
        "winAmount": 200
      }
    ],
    "players": [
      {
        "playerId": 1,
        "handName": "同花",
        "handRank": 5
      },
      {
        "playerId": 2,
        "handName": "高牌",
        "handRank": 0
      }
    ]
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `winners` | array | 赢家列表（可能多人平分） |
| `winners[].playerId` | int | 赢家 ID |
| `winners[].handName` | string | 牌型中文名 |
| `winners[].handRank` | int | 牌型等级 0~9 |
| `winners[].winAmount` | int | 赢得筹码 |
| `players` | array | 所有摊牌玩家的牌型 |
| `players[].playerId` | int | 玩家 ID |
| `players[].handName` | string | 牌型中文名 |
| `players[].handRank` | int | 牌型等级 0~9 |

#### `error` — 错误信息

```json
{
  "type": "error",
  "data": {
    "code": "INVALID_ACTION",
    "message": "当前不是你行动"
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | string | 错误码，前端可用于分支处理 |
| `message` | string | 人类可读的错误描述 |

**错误码清单：**

| code | 含义 |
|------|------|
| `NOT_YOUR_TURN` | 当前不是该玩家行动 |
| `INVALID_ACTION` | 当前阶段不允许此操作 |
| `INSUFFICIENT_CHIPS` | 筹码不足 |
| `BELOW_MIN_RAISE` | 加注金额低于最小加注额 |
| `GAME_NOT_STARTED` | 游戏尚未开始 |
| `GAME_ALREADY_STARTED` | 游戏已在进行中 |
| `SEAT_TAKEN` | 座位已被占用 |
| `NOT_ENOUGH_PLAYERS` | 玩家不足，无法开始 |

#### `info` — 提示信息（可选）

```json
{
  "type": "info",
  "data": {
    "message": "玩家3 已出局"
  }
}
```

## 5. 前端渲染映射

### 5.1 数据 → UI 元素

| 数据字段 | UI 元素 | 说明 |
|---------|---------|------|
| `player.name` | `.player-name` | 玩家名称 |
| `player.isCurrent === true` | `.player-name.active` | 白色高亮 |
| `player.state === "out"` | `.player-name.empty` | 淡色显示 |
| `player.action` | `.status#pN-action` | 跟随 / 弃牌 / 让牌 / 加注 |
| `player.state` | `.status#pN-state` | 存活 / 出局 |
| `player.chips` | `#remaining-chips` | 剩余筹码 |
| `player.currentBet` | `#current-chips` | 当局筹码 |
| `communityCards[i]` | `.community-cards > .card:nth-child(i+1)` | 公共牌 |
| `player.hand[i]` | `.hand-cards > .card:nth-child(i+1)` | 手牌 |

### 5.2 phase → 按钮状态

| phase | 跟注 | 加注 | 让牌 | 弃牌 |
|-------|------|------|------|------|
| `idle` | 禁用 | 禁用 | 禁用 | 禁用 |
| `preflop` | 启用 | 启用 | 启用* | 启用 |
| `flop` | 启用 | 启用 | 启用* | 启用 |
| `turn` | 启用 | 启用 | 启用* | 启用 |
| `river` | 启用 | 启用 | 启用* | 启用 |
| `showdown` | 禁用 | 禁用 | 禁用 | 禁用 |

> \*「让牌」仅在 `currentBet == 0`（即当前轮无人下注）时启用，否则应显示为「跟注」或禁用。

### 5.3 `hand_result` → UI

- 收到 `hand_result` 后，在牌区上方显示赢家提示文字（如「玩家1 以 同花 赢得 200 筹码」）。
- 3 秒后自动消失或进入下一局。
- 若多人平分，逐行显示每位赢家。

## 6. 状态转换时数据有效性规则

| 转换 | 规则 |
|------|------|
| idle → preflop | 所有 `state != "out"` 的玩家 `hand` 变为 2 张；`action` 清空；`currentBet` 置为大盲注 |
| preflop → flop | `communityCards` 变为 3 张；所有未弃牌玩家 `currentBet` 清零；`currentBet` 重置为 0 |
| flop → turn | `communityCards` 追加 1 张（共 4） |
| turn → river | `communityCards` 追加 1 张（共 5） |
| river → showdown | 调用 C++ 比牌，生成 `hand_result` |
| showdown → idle | `hand` 全部清空；`communityCards` 清空；`chips == 0` 的玩家 `state = "out"`；`dealerIndex` 轮换 |
