# 德州扑克 后端架构

---

## 概述

本项目的后端分为两层：

| 层 | 语言 | 职责 |
|----|------|------|
| 网络服务 + 游戏调度 | Python | WebSocket、状态机、发牌、下注、JSON |
| 牌型判断引擎 | C++ | 7选5最优组合、两手牌比较 |

Python 在 showdown 阶段通过 `ctypes` 调用 C++ 编译的 `hand_eval.dll`，其余逻辑全部在 Python 中完成。

---

```
HTML/CSS/JS 前端完成
       │
       ▼
  Tauri 打包 ────→ 独立桌面程序 (.exe)

       ├── WebView 渲染前端 UI
       └── 内嵌 Python 服务 + C++ 牌型库（sidecar 子进程）
              │
              └── WebSocket ws://127.0.0.1:9001
```

## 一、Python 服务（游戏调度 + 网络）

### 1.1 deck.py — 牌组

```python
import random

RANK_MAP  = {0:"2",1:"3",2:"4",3:"5",4:"6",5:"7",6:"8",7:"9",8:"10",9:"J",10:"Q",11:"K",12:"A"}
SUIT_MAP  = {0:"♠",1:"♥",2:"♦",3:"♣"}
RANK_REV  = {v:k for k,v in RANK_MAP.items()}
SUIT_REV  = {v:k for k,v in SUIT_MAP.items()}

class Deck:
    def __init__(self):
        self.cards: list[int] = []   # 0~51

    def shuffle(self):
        """重置为 52 张并洗牌"""
        self.cards = list(range(52))
        random.shuffle(self.cards)

    def deal(self, n: int) -> list[int]:
        """发 n 张牌，返回 card_id 列表"""
        return [self.cards.pop() for _ in range(n)]

def card_id_to_json(card_id: int) -> dict:
    """0~51 → {"suit":"♠","rank":"A"}"""
    return {"suit": SUIT_MAP[card_id % 4], "rank": RANK_MAP[card_id // 4]}

def json_to_card_id(card: dict) -> int:
    """{"suit":"♠","rank":"A"} → 0~51"""
    return RANK_REV[card["rank"]] * 4 + SUIT_REV[card["suit"]]
```

**对外接口：**

| 方法 | 说明 |
|------|------|
| `Deck()` | 构造空牌组 |
| `deck.shuffle()` | 重置 52 张并随机洗牌 |
| `deck.deal(n)` | 返回 n 个 `card_id`（int 0~51） |
| `card_id_to_json(id)` | int → 前端 JSON 格式 |
| `json_to_card_id(card)` | 前端 JSON → int |

### 1.2 player.py — 玩家

```python
class Player:
    def __init__(self, seat: int):
        self.id = seat
        self.name = f"玩家{seat}"   # 默认名称，可通过 set_name() 自定义
        self.chips = 1000          # 初始筹码
        self.currentBet = 0
        self.hand: list[int] = []  # card_id 列表
        self.action = ""           # fold/check/call/raise/""
        self.state = "active"      # active/folded/out
        self.isCurrent = False

    def set_name(self, name: str):
        """
        设置玩家自定义名称。
        前端在 join 时传入用户名，后端调用此方法更新。
        约束：长度 1~12 个字符，不能为空或纯空格。
        """
        self.name = name.strip()[:12]

    def reset_for_new_hand(self):
        """每局开始前重置（不重置 name，名称跨局保持）"""
        self.hand = []
        self.currentBet = 0
        self.action = ""
        if self.chips == 0:
            self.state = "out"
        elif self.state == "folded":
            self.state = "active"

    def to_json(self) -> dict:
        """序列化为前端 JSON"""
        return {
            "id": self.id,
            "name": self.name,
            "chips": self.chips,
            "currentBet": self.currentBet,
            "hand": [card_id_to_json(c) for c in self.hand],
            "action": self.action,
            "state": self.state,
            "isCurrent": self.isCurrent,
        }
```

**对外接口：**

| 方法 | 说明 |
|------|------|
| `Player(seat)` | 构造，初始筹码 1000，默认名称 "玩家{seat}" |
| `player.set_name(name)` | 设置自定义名称（join 时调用），长度限制 1~12 字符 |
| `player.reset_for_new_hand()` | 清零 hand/currentBet/action；chips==0 则 state="out"；**name 不重置** |
| `player.to_json()` | 序列化为前端 JSON |

### 1.3 game.py — 游戏状态机

#### 状态机

```
 idle ──→ preflop ──→ flop ──→ turn ──→ river ──→ showdown ──→ idle
```

#### 常量

```python
SMALL_BLIND = 10
BIG_BLIND   = 20
```

#### Game 类核心方法签名

```python
class Game:
    def __init__(self):
        self.phase = "idle"
        self.players: list[Player] = [Player(i+1) for i in range(8)]
        self.deck = Deck()
        self.community_cards: list[int] = []
        self.pot = 0
        self.currentBet = 0
        self.dealerIndex = 0
        self.currentPlayerIndex = -1
        self.minRaise = BIG_BLIND
        self._last_raiser_index = -1     # 本轮最后加注者
        self._acted_count = 0            # 本轮已行动人数

    # ── 对外入口 ──
    def process_action(self, player_id: int, action: str, amount: int = 0) -> dict:
        """WebSocket 消息处理入口，返回 {"ok": True} 或 {"error": ...}"""

    # ── 内部方法 ──
    def _start_new_hand(self):
        """idle → preflop"""

    def _advance_phase(self):
        """preflop→flop→turn→river→showdown"""

    def _end_hand(self):
        """showdown → idle"""

    def _next_player(self):
        """移动行动权到下一位未弃牌玩家；可能触发 _advance_phase()"""

    def _evaluate_showdown(self) -> dict:
        """收集 7 张牌数组，调用 C++ compare_hands，返回 hand_result"""

    def _is_betting_round_over(self) -> bool:
        """判断当前下注轮是否结束"""

    def to_json(self) -> dict:
        """序列化 GameState"""
```

#### 各阶段详细逻辑

##### idle → preflop（`_start_new_hand`）

```
1. deck.shuffle()
2. 遍历 players：调用 player.reset_for_new_hand()
3. 给每个 state=="active" 的玩家发 2 张手牌（deck.deal(2)）
4. 小盲注玩家（dealerIndex 下一位 active）扣除 SMALL_BLIND，currentBet = SMALL_BLIND
5. 大盲注玩家（小盲下一位 active）扣除 BIG_BLIND，currentBet = BIG_BLIND
6. pot = SMALL_BLIND + BIG_BLIND
7. currentBet = BIG_BLIND
8. minRaise = BIG_BLIND
9. currentPlayerIndex = 大盲注下一位 active 玩家
10. _last_raiser_index = 大盲注玩家索引
11. _acted_count = 0
12. phase = "preflop"
```

##### preflop → flop（`_advance_phase`）

```
1. 烧一张牌（deck.deal(1) 丢弃）
2. 发 3 张公共牌 → community_cards
3. 所有未弃牌玩家 currentBet 清零
4. currentBet = 0, minRaise = BIG_BLIND
5. currentPlayerIndex = dealerIndex 下一位 active（小盲位置）
6. _last_raiser_index = -1, _acted_count = 0
7. phase = "flop"
```

##### flop → turn / turn → river

```
1. 烧一张牌
2. 发 1 张公共牌追加到 community_cards
3. 同 flop 步骤 3~6
4. phase = "turn" / "river"
```

##### river → showdown（`_advance_phase`）

```
1. phase = "showdown"
2. 调用 _evaluate_showdown() 生成 hand_result
3. 广播 hand_result
4. 等待 3 秒后调用 _end_hand()
```

##### showdown → idle（`_end_hand`）

```
1. 所有玩家 hand 清空
2. community_cards 清空
3. pot = 0
4. chips == 0 的玩家 state = "out"
5. dealerIndex 轮换到下一位 state != "out" 的玩家
6. phase = "idle"
```

#### 下注轮控制逻辑（`_is_betting_round_over`）

一圈结束的条件：

```
当行动权回到 _last_raiser_index（最后加注者），
或所有未弃牌玩家都已行动且下注额相等时，本轮结束。
```

特殊情况：除一人外全部弃牌 → 直接跳至 showdown，该玩家赢得全部底池。

#### `process_action` 伪代码

```python
def process_action(self, player_id, action, amount=0):
    player = self.players[player_id - 1]

    # 校验
    if self.phase in ("idle", "showdown"):
        return {"error": "GAME_NOT_STARTED"}
    if player.id != self.currentPlayerIndex + 1:
        return {"error": "NOT_YOUR_TURN"}
    if player.state != "active":
        return {"error": "INVALID_ACTION"}

    if action == "fold":
        player.action = "fold"
        player.state = "folded"

    elif action == "check":
        if self.currentBet > 0:
            return {"error": "INVALID_ACTION"}  # 有人下注不能 check
        player.action = "check"

    elif action == "call":
        call_amount = self.currentBet - player.currentBet
        if call_amount > player.chips:
            call_amount = player.chips  # all-in
        player.chips -= call_amount
        player.currentBet += call_amount
        self.pot += call_amount
        player.action = "call"

    elif action == "raise":
        if amount < self.minRaise or amount > player.chips:
            return {"error": "BELOW_MIN_RAISE"}
        player.chips -= amount
        player.currentBet += amount
        self.pot += amount
        self.currentBet = player.currentBet
        self.minRaise = amount - self.currentBet  # 简化：加注差额
        self._last_raiser_index = self.currentPlayerIndex
        player.action = "raise"

    self._acted_count += 1
    self._next_player()
    return {"ok": True}
```

#### `_evaluate_showdown` 伪代码

```python
def _evaluate_showdown(self):
    active_players = [p for p in self.players if p.state == "active"]
    if len(active_players) == 1:
        # 其他人全弃牌，直接赢
        winner = active_players[0]
        winner.chips += self.pot
        return self._build_hand_result([winner], [])

    # 构建 7 张牌数组，调用 C++
    results = []
    for p in active_players:
        cards_7 = p.hand + self.community_cards  # 2 + 5 = 7
        rank = lib.eval_hand(to_c_array(cards_7))
        results.append((p, rank))

    # 找出最高牌型
    max_rank = max(r[1] for r in results)
    winners = [r[0] for r in results if r[1] == max_rank]

    # 如果多个同等级，调用 compare_hands 两两比较踢脚
    if len(winners) > 1:
        winners = self._tiebreak(winners)

    # 分配底池
    share = self.pot // len(winners)
    for w in winners:
        w.chips += share

    return self._build_hand_result(winners, results)
```

### 1.4 main.py — WebSocket 服务

#### 启动参数

- IP: `127.0.0.1`
- 端口: `9001`
- 库: `asyncio` + `websockets`

#### 连接管理

```python
connected = {}  # websocket → player_id
game = Game()
```

#### 消息处理白名单

| phase | 允许的消息 | 说明 |
|-------|-----------|------|
| `idle` | `join`, `start_game` | `join` 需携带 `seat`(1~8) 和 `name`(1~12字符，可选，默认"玩家{seat}") |
| `preflop`~`river` | `player_action`（仅当前玩家） | |
| `showdown` | 无（等待自动过渡） | |

#### 通信时序

```
1. 前端 WebView 连接 ws://127.0.0.1:9001
2. 前端发送 join { seat: 1, name: "小明" } → 服务端记录连接并设置玩家名称
3. 重复直到 ≥2 名玩家加入
4. 前端发送 start_game → 服务端 _start_new_hand()
5. 服务端广播 game_state → 前端渲染（含自定义名称）
6. 当前玩家点击按钮 → 前端发送 player_action
7. 服务端 process_action() → 广播 game_state
8. 重复 6~7 直到 showdown
9. 服务端广播 hand_result → 前端显示赢家（含自定义名称）
10. 3 秒后 _end_hand() → 广播 game_state (phase=idle)
```

#### 断线处理

- WebSocket 断开时，若该玩家正在游戏中且 `state == "active"`，自动将其设为 `fold`。
- 玩家可重新连接并发送 `join` 回到原座位。
- 若所有玩家断开，游戏状态保留，等待重连。

#### 核心代码骨架

```python
import asyncio
import json
from websockets.asyncio.server import serve
from game import Game

game = Game()
connections = {}  # player_id → websocket

async def handler(websocket):
    player_id = None
    async for raw in websocket:
        msg = json.loads(raw)
        msg_type = msg["type"]

        if msg_type == "join":
            seat = msg["data"]["seat"]
            name = msg["data"].get("name", f"玩家{seat}")
            player_id = seat
            connections[player_id] = websocket
            game.players[seat - 1].set_name(name)
            await websocket.send(json.dumps({"type":"info","data":{"message":f"{name} 已加入座位{seat}"}}))

        elif msg_type == "start_game":
            if game.phase != "idle":
                await websocket.send(json.dumps({"type":"error","data":{"code":"GAME_ALREADY_STARTED","message":"游戏已在进行中"}}))
                continue
            active_count = sum(1 for p in game.players if p.state != "out")
            if active_count < 2:
                await websocket.send(json.dumps({"type":"error","data":{"code":"NOT_ENOUGH_PLAYERS","message":"玩家不足"}}))
                continue
            game._start_new_hand()
            await broadcast_game_state()

        elif msg_type == "player_action":
            data = msg["data"]
            result = game.process_action(player_id, data["action"], data.get("amount", 0))
            if "error" in result:
                await websocket.send(json.dumps({"type":"error","data":{"code":result["error"],"message":result["error"]}}))
            else:
                await broadcast_game_state()
                if game.phase == "showdown":
                    await broadcast_hand_result()
                    await asyncio.sleep(3)
                    game._end_hand()
                    await broadcast_game_state()

async def broadcast_game_state():
    msg = json.dumps({"type":"game_state","data":game.to_json()})
    for ws in connections.values():
        await ws.send(msg)

async def broadcast_hand_result():
    result = game._evaluate_showdown()
    msg = json.dumps({"type":"hand_result","data":result})
    for ws in connections.values():
        await ws.send(msg)

async def main():
    async with serve(handler, "127.0.0.1", 9001):
        await asyncio.get_running_loop().create_future()  # run forever

if __name__ == "__main__":
    asyncio.run(main())
```

## 二、C++ 牌型库

### 2.1 卡片编码（与数据结构.md 附录一致）

```
card_id = rank * 4 + suit    // 0~51
rank = card_id / 4           // 0~12 (2=0 ... A=12)
suit = card_id % 4           // 0=♠, 1=♥, 2=♦, 3=♣
```

### 2.2 C 导出接口

```c
// bind.cpp
extern "C" {

// 输入：7 张牌的 card_id 数组
// 返回：牌型等级 0~9（见 §2.4）
int eval_hand(const int cards[7]);

// 比较两手牌（各 7 张：2 手牌 + 5 公共牌）
// 返回：>0 表示 hand_a 大，<0 表示 hand_b 大，=0 平分
// 比较逻辑：先比牌型等级，同等级则按踢脚（kick）依次比较
int compare_hands(const int hand_a[7], const int hand_b[7]);

}
```

### 2.3 Python 调用方式

```python
import ctypes
import os

# 加载 DLL（路径相对于 server/ 目录）
dll_path = os.path.join(os.path.dirname(__file__), "..", "engine", "hand_eval.dll")
lib = ctypes.CDLL(dll_path)

lib.eval_hand.argtypes = [ctypes.POINTER(ctypes.c_int)]
lib.eval_hand.restype = ctypes.c_int

lib.compare_hands.argtypes = [ctypes.POINTER(ctypes.c_int), ctypes.POINTER(ctypes.c_int)]
lib.compare_hands.restype = ctypes.c_int

def eval_hand(cards: list[int]) -> int:
    arr = (ctypes.c_int * 7)(*cards)
    return lib.eval_hand(arr)

def compare_hands(hand_a: list[int], hand_b: list[int]) -> int:
    arr_a = (ctypes.c_int * 7)(*hand_a)
    arr_b = (ctypes.c_int * 7)(*hand_b)
    return lib.compare_hands(arr_a, arr_b)
```

### 2.4 牌型等级

| 等级 | 牌型 | 中文名 |
|------|------|--------|
| 9 | Royal Flush | 皇家同花顺 |
| 8 | Straight Flush | 同花顺 |
| 7 | Four of a Kind | 四条 |
| 6 | Full House | 葫芦 |
| 5 | Flush | 同花 |
| 4 | Straight | 顺子 |
| 3 | Three of a Kind | 三条 |
| 2 | Two Pair | 两对 |
| 1 | One Pair | 一对 |
| 0 | High Card | 高牌 |

### 2.5 `compare_hands` 踢脚比较规则

当两手牌 `eval_hand` 返回相同等级时，`compare_hands` 按以下逻辑比较：

1. 同等级下，比较构成牌型的关键牌（如两对先比大对再比小对，葫芦先比三条再比对子）。
2. 关键牌相同时，依次比较剩余踢脚牌（从大到小）。
3. 全部相同则返回 0（平分底池）。

### 1.1 deck.py — 牌组

```python
import random

RANK_MAP  = {0:"2",1:"3",2:"4",3:"5",4:"6",5:"7",6:"8",7:"9",8:"10",9:"J",10:"Q",11:"K",12:"A"}
SUIT_MAP  = {0:"♠",1:"♥",2:"♦",3:"♣"}
RANK_REV  = {v:k for k,v in RANK_MAP.items()}
SUIT_REV  = {v:k for k,v in SUIT_MAP.items()}

class Deck:
    def __init__(self):
        self.cards: list[int] = []   # 0~51

    def shuffle(self):
        """重置为 52 张并洗牌"""
        self.cards = list(range(52))
        random.shuffle(self.cards)

    def deal(self, n: int) -> list[int]:
        """发 n 张牌，返回 card_id 列表"""
        return [self.cards.pop() for _ in range(n)]

def card_id_to_json(card_id: int) -> dict:
    """0~51 → {"suit":"♠","rank":"A"}"""
    return {"suit": SUIT_MAP[card_id % 4], "rank": RANK_MAP[card_id // 4]}

def json_to_card_id(card: dict) -> int:
    """{"suit":"♠","rank":"A"} → 0~51"""
    return RANK_REV[card["rank"]] * 4 + SUIT_REV[card["suit"]]
```

| 方法 | 说明 |

| `deck.shuffle()` | 重置 52 张并随机洗牌 |
| `deck.deal(n)` | 返回 n 个 `card_id`（int 0~51） |
| `card_id_to_json(id)` | int → 前端 JSON 格式 |
| `json_to_card_id(card)` | 前端 JSON → int |

### 1.2 player.py — 玩家

```python
class Player:
    def __init__(self, seat: int):
        self.id = seat
        self.name = f"玩家{seat}"
        self.chips = 1000          # 初始筹码
        self.currentBet = 0
        self.hand: list[int] = []  # card_id 列表
        self.action = ""           # fold/check/call/raise/""
        self.state = "active"      # active/folded/out
        self.isCurrent = False

    def reset_for_new_hand(self):
        """每局开始前重置"""
        self.hand = []
        self.currentBet = 0
        self.action = ""
        if self.chips == 0:
            self.state = "out"
        elif self.state == "folded":
            self.state = "active"

    def to_json(self) -> dict:
        """序列化为前端 JSON"""
        return {
            "id": self.id,
            "name": self.name,
            "chips": self.chips,
            "currentBet": self.currentBet,
            "hand": [card_id_to_json(c) for c in self.hand],
            "action": self.action,
            "state": self.state,
            "isCurrent": self.isCurrent,
        }
```

| 方法 | 说明 |
|------|------|
| `Player(seat)` | 构造，初始筹码 1000 |
| `player.reset_for_new_hand()` | 清零 hand/currentBet/action；chips==0 则 state="out" |

### 1.3 game.py — 游戏状态机

#### 状态机

```
 idle ──→ preflop ──→ flop ──→ turn ──→ river ──→ showdown ──→ idle
```

#### 常量

```python
SMALL_BLIND = 10
BIG_BLIND   = 20
```

#### Game 类核心方法签名

```python
class Game:
    def __init__(self):
        self.phase = "idle"
        self.players: list[Player] = [Player(i+1) for i in range(8)]
        self.deck = Deck()
        self.community_cards: list[int] = []
        self.pot = 0
        self.currentBet = 0
        self.dealerIndex = 0
        self.currentPlayerIndex = -1
        self.minRaise = BIG_BLIND
        self._last_raiser_index = -1     # 本轮最后加注者
        self._acted_count = 0            # 本轮已行动人数

    # ── 对外入口 ──
    def process_action(self, player_id: int, action: str, amount: int = 0) -> dict:
        """WebSocket 消息处理入口，返回 {"ok": True} 或 {"error": ...}"""

    # ── 内部方法 ──
    def _start_new_hand(self):
        """idle → preflop"""

    def _advance_phase(self):
        """preflop→flop→turn→river→showdown"""

    def _end_hand(self):
        """showdown → idle"""

    def _next_player(self):
        """移动行动权到下一位未弃牌玩家；可能触发 _advance_phase()"""

    def _evaluate_showdown(self) -> dict:
        """收集 7 张牌数组，调用 C++ compare_hands，返回 hand_result"""

    def _is_betting_round_over(self) -> bool:
        """判断当前下注轮是否结束"""

    def to_json(self) -> dict:
        """序列化 GameState"""
```

#### 各阶段详细逻辑

##### idle → preflop（`_start_new_hand`）

```
1. deck.shuffle()
2. 遍历 players：调用 player.reset_for_new_hand()
3. 给每个 state=="active" 的玩家发 2 张手牌（deck.deal(2)）
4. 小盲注玩家（dealerIndex 下一位 active）扣除 SMALL_BLIND，currentBet = SMALL_BLIND
5. 大盲注玩家（小盲下一位 active）扣除 BIG_BLIND，currentBet = BIG_BLIND
6. pot = SMALL_BLIND + BIG_BLIND
7. currentBet = BIG_BLIND
8. minRaise = BIG_BLIND
9. currentPlayerIndex = 大盲注下一位 active 玩家
10. _last_raiser_index = 大盲注玩家索引
11. _acted_count = 0
12. phase = "preflop"
```

##### preflop → flop（`_advance_phase`）

```
1. 烧一张牌（deck.deal(1) 丢弃）
2. 发 3 张公共牌 → community_cards
3. 所有未弃牌玩家 currentBet 清零
4. currentBet = 0, minRaise = BIG_BLIND
5. currentPlayerIndex = dealerIndex 下一位 active（小盲位置）
6. _last_raiser_index = -1, _acted_count = 0
7. phase = "flop"
```

##### flop → turn / turn → river

```
1. 烧一张牌
2. 发 1 张公共牌追加到 community_cards
3. 同 flop 步骤 3~6
4. phase = "turn" / "river"
```

##### river → showdown（`_advance_phase`）

```
1. phase = "showdown"
2. 调用 _evaluate_showdown() 生成 hand_result
3. 广播 hand_result
4. 等待 3 秒后调用 _end_hand()
```

##### showdown → idle（`_end_hand`）

```
1. 所有玩家 hand 清空
2. community_cards 清空
3. pot = 0
4. chips == 0 的玩家 state = "out"
5. dealerIndex 轮换到下一位 state != "out" 的玩家
6. phase = "idle"
```

#### 下注轮控制逻辑（`_is_betting_round_over`）

一圈结束的条件：

```
当行动权回到 _last_raiser_index（最后加注者），
或所有未弃牌玩家都已行动且下注额相等时，本轮结束。
```

特殊情况：除一人外全部弃牌 → 直接跳至 showdown，该玩家赢得全部底池。

#### `process_action` 伪代码

```python
def process_action(self, player_id, action, amount=0):
    player = self.players[player_id - 1]

    # 校验
    if self.phase in ("idle", "showdown"):
        return {"error": "GAME_NOT_STARTED"}
    if player.id != self.currentPlayerIndex + 1:
        return {"error": "NOT_YOUR_TURN"}
    if player.state != "active":
        return {"error": "INVALID_ACTION"}

    if action == "fold":
        player.action = "fold"
        player.state = "folded"

    elif action == "check":
        if self.currentBet > 0:
            return {"error": "INVALID_ACTION"}  # 有人下注不能 check
        player.action = "check"

    elif action == "call":
        call_amount = self.currentBet - player.currentBet
        if call_amount > player.chips:
            call_amount = player.chips  # all-in
        player.chips -= call_amount
        player.currentBet += call_amount
        self.pot += call_amount
        player.action = "call"

    elif action == "raise":
        if amount < self.minRaise or amount > player.chips:
            return {"error": "BELOW_MIN_RAISE"}
        player.chips -= amount
        player.currentBet += amount
        self.pot += amount
        self.currentBet = player.currentBet
        self.minRaise = amount - self.currentBet  # 简化：加注差额
        self._last_raiser_index = self.currentPlayerIndex
        player.action = "raise"

    self._acted_count += 1
    self._next_player()
    return {"ok": True}
```

#### `_evaluate_showdown` 伪代码

```python
def _evaluate_showdown(self):
    active_players = [p for p in self.players if p.state == "active"]
    if len(active_players) == 1:
        # 其他人全弃牌，直接赢
        winner = active_players[0]
        winner.chips += self.pot
        return self._build_hand_result([winner], [])

    # 构建 7 张牌数组，调用 C++
    results = []
    for p in active_players:
        cards_7 = p.hand + self.community_cards  # 2 + 5 = 7
        rank = lib.eval_hand(to_c_array(cards_7))
        results.append((p, rank))

    # 找出最高牌型
    max_rank = max(r[1] for r in results)
    winners = [r[0] for r in results if r[1] == max_rank]

    # 如果多个同等级，调用 compare_hands 两两比较踢脚
    if len(winners) > 1:
        winners = self._tiebreak(winners)

    # 分配底池
    share = self.pot // len(winners)
    for w in winners:
        w.chips += share

    return self._build_hand_result(winners, results)
```

### 1.4 main.py — WebSocket 服务

#### 启动参数

- IP: `127.0.0.1`
- 端口: `9001`
- 库: `asyncio` + `websockets`

#### 连接管理

```python
connected = {}  # websocket → player_id
game = Game()
```

#### 消息处理白名单

| phase | 允许的消息 |
|-------|-----------|
| `idle` | `join`, `start_game` |
| `preflop`~`river` | `player_action`（仅当前玩家） |
| `showdown` | 无（等待自动过渡） |

#### 通信时序

```
1. 前端 WebView 连接 ws://127.0.0.1:9001
2. 前端发送 join { seat: 1 } → 服务端记录连接
3. 重复直到 ≥2 名玩家加入
4. 前端发送 start_game → 服务端 _start_new_hand()
5. 服务端广播 game_state → 前端渲染
6. 当前玩家点击按钮 → 前端发送 player_action
7. 服务端 process_action() → 广播 game_state
8. 重复 6~7 直到 showdown
9. 服务端广播 hand_result → 前端显示赢家
10. 3 秒后 _end_hand() → 广播 game_state (phase=idle)
```

#### 断线处理

- WebSocket 断开时，若该玩家正在游戏中且 `state == "active"`，自动将其设为 `fold`。
- 玩家可重新连接并发送 `join` 回到原座位。
- 若所有玩家断开，游戏状态保留，等待重连。

#### 核心代码骨架

```python
import asyncio
import json
from websockets.asyncio.server import serve
from game import Game

game = Game()
connections = {}  # player_id → websocket

async def handler(websocket):
    player_id = None
    async for raw in websocket:
        msg = json.loads(raw)
        msg_type = msg["type"]

        if msg_type == "join":
            seat = msg["data"]["seat"]
            player_id = seat
            connections[player_id] = websocket
            await websocket.send(json.dumps({"type":"info","data":{"message":f"玩家{seat} 已加入"}}))

        elif msg_type == "start_game":
            if game.phase != "idle":
                await websocket.send(json.dumps({"type":"error","data":{"code":"GAME_ALREADY_STARTED","message":"游戏已在进行中"}}))
                continue
            active_count = sum(1 for p in game.players if p.state != "out")
            if active_count < 2:
                await websocket.send(json.dumps({"type":"error","data":{"code":"NOT_ENOUGH_PLAYERS","message":"玩家不足"}}))
                continue
            game._start_new_hand()
            await broadcast_game_state()

        elif msg_type == "player_action":
            data = msg["data"]
            result = game.process_action(player_id, data["action"], data.get("amount", 0))
            if "error" in result:
                await websocket.send(json.dumps({"type":"error","data":{"code":result["error"],"message":result["error"]}}))
            else:
                await broadcast_game_state()
                if game.phase == "showdown":
                    await broadcast_hand_result()
                    await asyncio.sleep(3)
                    game._end_hand()
                    await broadcast_game_state()

async def broadcast_game_state():
    msg = json.dumps({"type":"game_state","data":game.to_json()})
    for ws in connections.values():
        await ws.send(msg)

async def broadcast_hand_result():
    result = game._evaluate_showdown()
    msg = json.dumps({"type":"hand_result","data":result})
    for ws in connections.values():
        await ws.send(msg)

async def main():
    async with serve(handler, "127.0.0.1", 9001):
        await asyncio.get_running_loop().create_future()  # run forever

if __name__ == "__main__":
    asyncio.run(main())
```

### 2.1 卡片编码（与数据结构.md 附录一致）

### 2.2 C 导出接口

```c
// bind.cpp
extern "C" {

// 输入：7 张牌的 card_id 数组
// 返回：牌型等级 0~9（见 §2.4）
int eval_hand(const int cards[7]);

// 比较两手牌（各 7 张：2 手牌 + 5 公共牌）
// 返回：>0 表示 hand_a 大，<0 表示 hand_b 大，=0 平分
// 比较逻辑：先比牌型等级，同等级则按踢脚（kick）依次比较
int compare_hands(const int hand_a[7], const int hand_b[7]);

}
```

### 2.3 Python 调用方式

```python
import ctypes
import os

# 加载 DLL（路径相对于 server/ 目录）
dll_path = os.path.join(os.path.dirname(__file__), "..", "engine", "build", "hand_eval.dll")
lib = ctypes.CDLL(dll_path)

lib.eval_hand.argtypes = [ctypes.POINTER(ctypes.c_int)]
lib.eval_hand.restype = ctypes.c_int

lib.compare_hands.argtypes = [ctypes.POINTER(ctypes.c_int), ctypes.POINTER(ctypes.c_int)]
lib.compare_hands.restype = ctypes.c_int

def eval_hand(cards: list[int]) -> int:
    arr = (ctypes.c_int * 7)(*cards)
    return lib.eval_hand(arr)

def compare_hands(hand_a: list[int], hand_b: list[int]) -> int:
    arr_a = (ctypes.c_int * 7)(*hand_a)
    arr_b = (ctypes.c_int * 7)(*hand_b)
    return lib.compare_hands(arr_a, arr_b)
```

### 2.4 牌型等级

| 等级 | 牌型 | 中文名 |
|------|------|--------|
| 9 | Royal Flush | 皇家同花顺 |
| 8 | Straight Flush | 同花顺 |
| 7 | Four of a Kind | 四条 |
| 6 | Full House | 葫芦 |
| 5 | Flush | 同花 |
| 4 | Straight | 顺子 |
| 3 | Three of a Kind | 三条 |
| 2 | Two Pair | 两对 |
| 1 | One Pair | 一对 |
| 0 | High Card | 高牌 |

### 2.5 `compare_hands` 踢脚比较规则

当两手牌 `eval_hand` 返回相同等级时，`compare_hands` 按以下逻辑比较：

1. 同等级下，比较构成牌型的关键牌（如两对先比大对再比小对，葫芦先比三条再比对子）。
2. 关键牌相同时，依次比较剩余踢脚牌（从大到小）。
3. 全部相同则返回 0（平分底池）。

## 五、调试方法

1. **C++ 库单独测试**：写一个 C++ `main()` 调用 `eval_hand` 和 `compare_hands`，验证各种牌型。
2. **Python 单元测试**：`pytest` 测试 `Deck.deal()` 不重复、`Game.process_action()` 各种边界。
3. **前后端联调**：浏览器打开 `index.html`，F12 控制台查看 WebSocket 消息。
4. **Tauri 调试**：`npm run tauri dev` 打开开发者工具。
