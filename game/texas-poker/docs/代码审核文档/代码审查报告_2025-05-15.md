## 额外修复问题

### P-019 静态资源处理器拦截 API 路由

| 项目 | 内容 |
|------|------|
| **问题描述** | `STATIC_URL_PREFIX = "/"` 导致所有请求都被静态处理器拦截，API 路由无法匹配 |
| **修复状态** | ✅ 已修复 |
| **修复方案** | 修改 `server.py` 中的请求处理顺序，优先匹配 `/api/` 路径和根路径到路由分发器，再回退到静态文件处理 |
| **验证结果** | ✅ API 路由和静态文件均可正常访问 |

### P-020 Player.reset_for_new_hand() 筹码重置逻辑错误

| 项目 | 内容 |
|------|------|
| **问题描述** | `reset_for_new_hand()` 仅在 `chips <= 0` 时重置筹码，导致正常玩家无法获得初始筹码 |
| **修复状态** | ✅ 已修复 |
| **修复方案** | 修改为 `if initial_chips is not None: self.chips = initial_chips`，每局开始时重置所有玩家筹码 |
| **验证结果** | ✅ 筹码重置逻辑正确 |
