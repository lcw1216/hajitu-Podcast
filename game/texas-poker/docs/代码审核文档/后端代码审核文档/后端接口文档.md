## 1. 概述

### 1.1 服务说明

德州扑克 HTTP 服务器提供 RESTful API 接口，用于用户管理、房间管理、游戏数据查询和静态资源服务。游戏实时通信仍通过 WebSocket 协议完成。

### 1.2 服务信息

| 项目 | 值 |
|------|-----|
| 服务名称 | Texas Poker Server |
| 版本 | 1.0 |
| 协议 | HTTP/1.1 |
| 默认地址 | `http://127.0.0.1:9001` |
| 字符编码 | UTF-8 |
| 时间格式 | `YYYY-MM-DD HH:MM:SS` (UTC+8) |

### 1.3 数据库表结构

#### users 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 用户ID |
| username | TEXT | UNIQUE NOT NULL | 用户名 |
| password | TEXT | NOT NULL | 密码 |
| chips | INTEGER | DEFAULT 1000 | 筹码余额 |
| created_at | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

#### rooms 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 房间ID |
| name | TEXT | NOT NULL | 房间名称 |
| max_players | INTEGER | DEFAULT 8 | 最大玩家数 |
| initial_chips | INTEGER | DEFAULT 1000 | 初始筹码 |
| created_by | INTEGER | FOREIGN KEY → users(id) | 创建者ID |
| created_at | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

#### game_logs 表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 日志ID |
| room_id | INTEGER | FOREIGN KEY → rooms(id) | 房间ID |
| player_id | INTEGER | FOREIGN KEY → users(id) | 玩家ID |
| action | TEXT | - | 操作类型 |
| amount | INTEGER | DEFAULT 0 | 操作金额 |
| created_at | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 操作时间 |

## 2. 通用约定

### 2.1 请求格式

- 所有 POST 请求的请求体必须使用 JSON 格式
- 请求头必须包含 `Content-Type: application/json`
- 请求体最大大小：1MB（1,048,576 字节）

### 2.2 响应格式

所有 API 响应均为 JSON 格式，包含以下通用字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| ok | boolean | 请求是否成功 |

成功响应示例：
```json
{
  "ok": true,
  "...": "其他业务数据"
}
```

错误响应格式（JSON）：
```json
{
  "ok": false,
  "error": {
    "code": 400,
    "message": "Bad Request"
  }
}
```

所有错误响应均使用此JSON格式，包含 `ok`、`error.code` 和 `error.message` 字段。

### 2.3 通用响应头

每个响应都包含以下头部：

| 响应头 | 值 | 说明 |
|--------|-----|------|
| Content-Type | application/json; charset=utf-8 | 响应内容类型 |
| Server | TexasPoker/1.0 | 服务器标识 |
| Date | RFC 2822 格式 | 响应时间 |
| Connection | close | 短连接 |
| X-Content-Type-Options | nosniff | 禁止 MIME 嗅探 |
| X-XSS-Protection | 1; mode=block | XSS 防护 |
| X-Frame-Options | DENY | 禁止 iframe 嵌入 |
| Access-Control-Allow-Origin | * | CORS 允许来源 |
| Access-Control-Allow-Methods | GET, POST, PUT, DELETE, OPTIONS | CORS 允许方法 |
| Access-Control-Allow-Headers | Content-Type, Authorization | CORS 允许头部 |
| Access-Control-Max-Age | 86400 | CORS 预检缓存时间 |

### 2.4 路径参数

路径参数使用 `:param` 格式定义，例如 `/api/users/:user_id` 中的 `:user_id` 为路径参数。

### 2.5 查询参数

查询参数附加在 URL 后，格式为 `?key=value&key2=value2`。

## 4. 用户接口

### 4.1 用户注册

创建新用户账号。

| 项目 | 值 |
|------|-----|
| **接口名称** | 用户注册 |
| **请求路径** | `/api/register` |
| **请求方法** | POST |
| **权限要求** | 无 |

#### 请求参数

**请求体 (Body)** — `Content-Type: application/json`

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| username | string | **是** | - | 用户名，2~20个字符 |
| password | string | **是** | - | 密码，不能为空 |

#### 成功响应

**状态码**: 201 Created

| 字段 | 类型 | 说明 |
|------|------|------|
| ok | boolean | 固定值 `true` |
| user_id | integer | 新创建的用户ID |
| username | string | 用户名 |

#### 错误响应

| 状态码 | 说明 | 触发条件 |
|--------|------|----------|
| 400 | Bad Request | 缺少 username 或 password；用户名长度不在 2~20 范围；用户名已存在 |

#### 请求示例

```bash
curl -X POST http://127.0.0.1:9001/api/register \
  -H "Content-Type: application/json" \
  -d '{
    "username": "player1",
    "password": "mypassword"
  }'
```

#### 成功响应示例

```json
{
  "ok": true,
  "user_id": 1,
  "username": "player1"
}
```

#### 错误响应示例

```json
{
  "ok": false,
  "error": {
    "code": 400,
    "message": "username and password are required"
  }
}
```

```json
{
  "ok": false,
  "error": {
    "code": 400,
    "message": "username already exists"
  }
}
```

```json
{
  "ok": false,
  "error": {
    "code": 400,
    "message": "username must be 2-20 characters"
  }
}
```

#### 特殊说明

- 用户名必须唯一，重复注册会返回 400 错误
- 当前版本密码以明文存储，仅供开发演示，生产环境请使用 bcrypt/argon2 加密
- 注册成功后用户默认获得 1000 筹码

### 4.2 用户登录

验证用户身份并返回用户信息。

| 项目 | 值 |
|------|-----|
| **接口名称** | 用户登录 |
| **请求路径** | `/api/login` |
| **请求方法** | POST |
| **权限要求** | 无 |

#### 请求参数

**请求体 (Body)** — `Content-Type: application/json`

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| username | string | **是** | - | 用户名 |
| password | string | **是** | - | 密码 |

#### 成功响应

**状态码**: 200 OK

| 字段 | 类型 | 说明 |
|------|------|------|
| ok | boolean | 固定值 `true` |
| user_id | integer | 用户ID |
| username | string | 用户名 |
| chips | integer | 当前筹码余额 |

#### 错误响应

| 状态码 | 说明 | 触发条件 |
|--------|------|----------|
| 400 | Bad Request | 缺少 username 或 password |
| 401 | Unauthorized | 用户名或密码错误 |

#### 请求示例

```bash
curl -X POST http://127.0.0.1:9001/api/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "player1",
    "password": "mypassword"
  }'
```

#### 成功响应示例

```json
{
  "ok": true,
  "user_id": 1,
  "username": "player1",
  "chips": 1000,
  "token": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
}
```

#### 错误响应示例

```json
{
  "ok": false,
  "error": {
    "code": 401,
    "message": "invalid username or password"
  }
}
```

#### 特殊说明

- 登录失败不区分"用户名不存在"和"密码错误"，统一返回 401
- 登录成功后会返回 `token` 字段，用于后续身份验证
- 当前版本使用 bcrypt 加密存储密码

| cards[].suit | string | 花色英文（spade, heart, diamond, club） |
| cards[].symbol | string | 花色符号（♠, ♥, ♦, ♣） |
| cards[].display | string | 显示文本（如 ♠A, ♥K） |

#### 卡牌编码规则

```
card_id = rank_index × 4 + suit_index

rank_index: 2→0, 3→1, 4→2, 5→3, 6→4, 7→5, 8→6, 9→7, 10→8, J→9, Q→10, K→11, A→12
suit_index: ♠→0, ♥→1, ♦→2, ♣→3

示例:
  ♠A = 12 × 4 + 0 = 48
  ♥K = 11 × 4 + 1 = 45
  ♣2 = 0 × 4 + 3 = 3
```


## 7. 静态资源接口

### 7.1 获取静态文件

提供图片、CSS、JS等静态资源文件服务。

| 项目 | 值 |
|------|-----|
| **接口名称** | 获取静态文件 |
| **请求路径** | `/static/{filename}` |
| **请求方法** | GET |
| **权限要求** | 无 |

#### 请求参数

**路径参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| filename | string | **是** | 文件相对路径，如 `ace_of_spades.png` |

#### 成功响应

**状态码**: 200 OK

响应体为文件的原始二进制内容，Content-Type 根据文件扩展名自动设置。

**支持的文件类型**

| 扩展名 | Content-Type |
|--------|-------------|
| .html | text/html; charset=utf-8 |
| .css | text/css; charset=utf-8 |
| .js | application/javascript; charset=utf-8 |
| .json | application/json; charset=utf-8 |
| .png | image/png |
| .jpg / .jpeg | image/jpeg |
| .gif | image/gif |
| .svg | image/svg+xml |
| .ico | image/x-icon |
| .woff | font/woff |
| .woff2 | font/woff2 |
| .ttf | font/ttf |
| .txt | text/plain; charset=utf-8 |
| .xml | application/xml |
| 其他 | application/octet-stream |

**响应头**

| 响应头 | 值 | 说明 |
|--------|-----|------|
| Cache-Control | public, max-age=3600 | 缓存1小时 |
| Accept-Ranges | bytes | 支持断点续传 |

#### 错误响应

| 状态码 | 说明 | 触发条件 |
|--------|------|----------|
| 403 | Forbidden | 路径遍历攻击（如 `/static/../../etc/passwd`） |
| 404 | Not Found | 文件不存在 |
| 413 | Payload Too Large | 文件超过 1MB |

#### 请求示例

```bash
# 获取扑克牌图片
curl http://127.0.0.1:9001/static/ace_of_spades.png --output ace.png

# 获取红心K图片
curl http://127.0.0.1:9001/static/king_of_hearts.png --output king.png
```

#### 可用资源列表

所有扑克牌图片位于 `picture/` 目录，命名规则为 `{rank}_of_{suit}.png`：

| 花色 | 文件名示例 |
|------|-----------|
| ♠ spades | `ace_of_spades.png`, `king_of_spades.png`, ..., `2_of_spades.png` |
| ♥ hearts | `ace_of_hearts.png`, `king_of_hearts.png`, ..., `2_of_hearts.png` |
| ♦ diamonds | `ace_of_diamonds.png`, `king_of_diamonds.png`, ..., `2_of_diamonds.png` |
| ♣ clubs | `ace_of_clubs.png`, `king_of_clubs.png`, ..., `2_of_clubs.png` |

#### 特殊说明

- 路径遍历攻击会被拦截，如 `/static/../../../etc/passwd` 将返回 403
- 文件大小超过 1MB 将返回 413
- 静态资源默认缓存 1 小时

## 8. 错误码参考

### 8.1 HTTP 状态码

| 状态码 | 含义 | 触发场景 |
|--------|------|----------|
| 200 | OK | 请求成功 |
| 201 | Created | 资源创建成功（注册/创建房间） |
| 400 | Bad Request | 请求参数错误、缺少必填字段、数据格式不正确 |
| 401 | Unauthorized | 认证失败（用户名或密码错误） |
| 403 | Forbidden | 无权访问（路径遍历攻击） |
| 404 | Not Found | 资源不存在（用户/房间/文件） |
| 405 | Method Not Allowed | 请求方法不被允许（如用 DELETE 访问只支持 GET 的接口） |
| 408 | Request Timeout | 请求超时（30秒） |
| 413 | Payload Too Large | 请求体或文件超过 1MB |
| 500 | Internal Server Error | 服务器内部错误 |

### 8.2 错误响应格式

错误响应为JSON格式，包含状态码和错误描述信息：

```json
HTTP/1.1 400 Bad Request
Content-Type: application/json; charset=utf-8

{
  "ok": false,
  "error": {
    "code": 400,
    "message": "username and password are required"
  }
}
```

| 接口 | 错误消息 | 状态码 |
|------|----------|--------|
| 注册 | `username and password are required` | 400 |

| 注册 | `username must be 2-20 characters` | 400 |
| 注册 | `username already exists` | 400 |
| 登录 | `username and password are required` | 400 |
| 登录 | `invalid username or password` | 401 |
| 用户信息 | `user not found` | 404 |
| 创建房间 | `room name is required` | 400 |
| 创建房间 | `room name must be at least 2 characters` | 400 |
| 房间详情 | `room not found` | 404 |
| 加入房间 | `user_id is required` | 400 |
| 加入房间 | `room not found` | 404 |
| 加入房间 | `user not found` | 404 |
| 静态资源 | `Access denied` | 403 |
| 静态资源 | `File not found: xxx` | 404 |

## 9. 限流策略

### 9.1 当前策略

| 项目 | 限制 | 说明 |
|------|------|------|
| 请求体大小 | 1MB | 超过返回 413 Payload Too Large |
| 请求超时 | 30秒 | 超过返回 408 Request Timeout |
| 静态文件大小 | 1MB | 超过返回 413 Payload Too Large |
| 并发连接 | 无硬性限制 | 受系统资源约束 |

### 9.2 性能基准

基于本地回环测试的基准数据：

| 指标 | 50并发 | 100并发 |
|------|--------|---------|
| 吞吐量 | ~2700 req/s | ~3200 req/s |
| 平均响应时间 | ~6ms | ~12ms |
| P99 响应时间 | ~11ms | ~21ms |
| 成功率 | 100% | 100% |
