## 1. 前言：这篇教程是什么

### 学完你能得到什么？

一个**完整可运行的德州扑克游戏后端**，它能够：

- 通过 WebSocket 接收前端（网页）发来的玩家操作
- 管理 8 名玩家的筹码、手牌、下注
- 自动控制游戏流程：发牌 → 翻牌 → 转牌 → 河牌 → 摊牌比大小
- 调用 C++ 编译的底层库来判断牌型（同花顺、葫芦、两对……）
- 把游戏状态实时推送给所有前端

### 为什么需要 C++？

德州扑克牌型判断需要从 7 张牌中选出最优的 5 张组合（C(7,5)=21 种），还要在同等级时比较踢脚牌。纯 Python 做这件事虽然可行，但 C++ 快得多，而且把"算牌"和"管游戏"分开，代码更清晰。

### 你需要会什么？

- 基本的 Python 语法（函数、类、列表、字典）
- 用过 `pip install` 安装库
- 知道什么是命令行 / 终端

**不需要**会 C++（代码已经写好，你只需要编译），也不需要了解 WebSocket 底层原理。

## 4. 卡片编码方案

### 为什么需要编码方案？

前端用 `{"suit": "♠", "rank": "A"}` 这种人类可读的格式显示牌面。但 Python 和 C++ 之间传数据时，用整数比用字符串高效得多，也不容易出错。

### 编码规则

每张牌用一个 **0~51** 的整数表示：

```
card_id = rank * 4 + suit
```

| 点数 | 编码 | | 点数 | 编码 |
|------|------|-|------|------|
| 2 | 0 | | 9 | 7 |
| 3 | 1 | | 10 | 8 |
| 4 | 2 | | J | 9 |
| 5 | 3 | | Q | 10 |
| 6 | 4 | | K | 11 |
| 7 | 5 | | A | 12 |
| 8 | 6 | | | |

| 花色 | 编码 |
|------|------|
| ♠ (spade) | 0 |
| ♥ (heart) | 1 |
| ♦ (diamond) | 2 |
| ♣ (club) | 3 |

### 举例

- 黑桃 A：`rank=12, suit=0` → `card_id = 12*4 + 0 = 48`
- 红心 10：`rank=8, suit=1` → `card_id = 8*4 + 1 = 33`
- 梅花 2：`rank=0, suit=3` → `card_id = 0*4 + 3 = 3`

### 解码

```python
rank = card_id // 4    # 整除
suit = card_id % 4     # 取余
```

> **重要：** Python 端和 C++ 端必须使用完全相同的编码公式，否则会出现"黑桃 A 被当成方块 2"这种离谱错误。

## 5. 第一步：C++ 牌型判断引擎

这是整个项目最"硬核"的部分，但代码已经写好了，你只需要**复制粘贴 + 编译**。

### 5.1 为什么先做 C++？

因为 Python 的 `game.py` 需要导入 C++ 编译出来的 `.dll`（或 `.so`）文件。如果 C++ 库没编译好，Python 端一启动就会报错。所以先编译 C++，再写 Python。

### 5.2 文件 1：`engine/hand_eval.h`（头文件）

```cpp
#ifndef HAND_EVAL_H
#define HAND_EVAL_H

#ifdef __cplusplus
extern "C" {
#endif

// 牌型等级常量
#define HAND_HIGH_CARD       0
#define HAND_ONE_PAIR        1
#define HAND_TWO_PAIR        2
#define HAND_THREE_OF_A_KIND 3
#define HAND_STRAIGHT        4
#define HAND_FLUSH           5
#define HAND_FULL_HOUSE      6
#define HAND_FOUR_OF_A_KIND  7
#define HAND_STRAIGHT_FLUSH  8
#define HAND_ROYAL_FLUSH     9

// 从 7 张牌中找出最优 5 张组合，返回牌型等级 (0~9)
// cards: 长度为 7 的 int 数组，每张牌编码为 rank*4+suit (0~51)
int eval_hand(const int cards[7]);

// 比较两手牌（各 7 张：2 手牌 + 5 公共牌）
// 返回: >0 表示 hand_a 大, <0 表示 hand_b 大, =0 平分
int compare_hands(const int hand_a[7], const int hand_b[7]);

#ifdef __cplusplus
}
#endif

#endif // HAND_EVAL_H
```

**关键解释：**

- `extern "C"` — 告诉 C++ 编译器"用 C 语言的方式导出函数名"。Python 的 `ctypes` 只能识别 C 风格的函数名，不能识别 C++ 的"名字修饰"（name mangling）。
- `eval_hand` — 输入 7 张牌，返回牌型等级（0=高牌, 9=皇家同花顺）。只返回等级数字，不返回踢脚信息。
- `compare_hands` — 比较两手完整的 7 张牌。先比牌型等级，同等级再比踢脚。返回正/负/零。

### 5.3 文件 2：`engine/hand_eval.cpp`（核心实现）

```cpp
#include "hand_eval.h"
#include <algorithm>
#include <cstring>

// 从 card_id 解码出点数 (0~12) 和花色 (0~3)
static inline int card_rank(int card) { return card / 4; }
static inline int card_suit(int card) { return card % 4; }

// 存储一手 5 张牌的评估结果
struct HandScore {
    int rank;        // 牌型等级 0~9
    int kickers[5];  // 踢脚牌点数，从大到小排列，用于同等级比较
};

// 比较两个 HandScore，返回 >0 表示 a 大
static int compare_scores(const HandScore& a, const HandScore& b) {
    if (a.rank != b.rank)
        return a.rank - b.rank;
    for (int i = 0; i < 5; i++) {
        if (a.kickers[i] != b.kickers[i])
            return a.kickers[i] - b.kickers[i];
    }
    return 0;
}

// 评估 5 张牌（已按点数从大到小排序）
static HandScore eval_5cards(const int cards[5]) {
    HandScore score;
    int ranks[5], suits[5];
    for (int i = 0; i < 5; i++) {
        ranks[i] = card_rank(cards[i]);
        suits[i] = card_suit(cards[i]);
    }

    // 统计点数出现次数
    int rank_counts[13] = {0};
    for (int i = 0; i < 5; i++)
        rank_counts[ranks[i]]++;

    // 找出四条、三条、对子
    int four_kind = -1, three_kind = -1;
    int pairs[2] = {-1, -1};
    int pair_count = 0;
    for (int r = 12; r >= 0; r--) {
        if (rank_counts[r] == 4) four_kind = r;
        if (rank_counts[r] == 3) three_kind = r;
        if (rank_counts[r] == 2) {
            pairs[pair_count++] = r;
        }
    }

    // 判断同花
    bool is_flush = true;
    for (int i = 1; i < 5; i++) {
        if (suits[i] != suits[0]) { is_flush = false; break; }
    }

    // 判断顺子（注意 A-2-3-4-5 的特殊情况）
    bool is_straight = false;
    int straight_high = -1;
    // 正常顺子检查
    if (ranks[0] - ranks[4] == 4) {
        bool consecutive = true;
        for (int i = 1; i < 5; i++) {
            if (ranks[i-1] - ranks[i] != 1) { consecutive = false; break; }
        }
        if (consecutive) {
            is_straight = true;
            straight_high = ranks[0];
        }
    }
    // A-2-3-4-5 (A=12, 但这里 A 当 0 用)
    if (!is_straight && ranks[0] == 12 && ranks[1] == 3 && ranks[2] == 2 &&
        ranks[3] == 1 && ranks[4] == 0) {
        is_straight = true;
        straight_high = 3;  // 5-high straight
    }

    // 按牌型等级从高到低判断
    if (is_flush && is_straight) {
        if (straight_high == 12) {
            score.rank = HAND_ROYAL_FLUSH;
        } else {
            score.rank = HAND_STRAIGHT_FLUSH;
        }
        score.kickers[0] = straight_high;
        for (int i = 1; i < 5; i++) score.kickers[i] = -1;
        return score;
    }

    if (four_kind >= 0) {
        score.rank = HAND_FOUR_OF_A_KIND;
        score.kickers[0] = four_kind;
        for (int i = 0; i < 5; i++) {
            if (ranks[i] != four_kind) {
                score.kickers[1] = ranks[i];
                break;
            }
        }
        for (int i = 2; i < 5; i++) score.kickers[i] = -1;
        return score;
    }

    if (three_kind >= 0 && pair_count >= 1) {
        score.rank = HAND_FULL_HOUSE;
        score.kickers[0] = three_kind;
        score.kickers[1] = pairs[0];
        for (int i = 2; i < 5; i++) score.kickers[i] = -1;
        return score;
    }

    if (is_flush) {
        score.rank = HAND_FLUSH;
        for (int i = 0; i < 5; i++) score.kickers[i] = ranks[i];
        return score;
    }

    if (is_straight) {
        score.rank = HAND_STRAIGHT;
        score.kickers[0] = straight_high;
        for (int i = 1; i < 5; i++) score.kickers[i] = -1;
        return score;
    }

    if (three_kind >= 0) {
        score.rank = HAND_THREE_OF_A_KIND;
        score.kickers[0] = three_kind;
        int ki = 1;
        for (int i = 0; i < 5; i++) {
            if (ranks[i] != three_kind)
                score.kickers[ki++] = ranks[i];
        }
        for (int i = ki; i < 5; i++) score.kickers[i] = -1;
        return score;
    }

    if (pair_count == 2) {
        score.rank = HAND_TWO_PAIR;
        score.kickers[0] = pairs[0];  // 大对
        score.kickers[1] = pairs[1];  // 小对
        for (int i = 0; i < 5; i++) {
            if (ranks[i] != pairs[0] && ranks[i] != pairs[1]) {
                score.kickers[2] = ranks[i];
                break;
            }
        }
        for (int i = 3; i < 5; i++) score.kickers[i] = -1;
        return score;
    }

    if (pair_count == 1) {
        score.rank = HAND_ONE_PAIR;
        score.kickers[0] = pairs[0];
        int ki = 1;
        for (int i = 0; i < 5; i++) {
            if (ranks[i] != pairs[0])
                score.kickers[ki++] = ranks[i];
        }
        for (int i = ki; i < 5; i++) score.kickers[i] = -1;
        return score;
    }

    // 高牌
    score.rank = HAND_HIGH_CARD;
    for (int i = 0; i < 5; i++) score.kickers[i] = ranks[i];
    return score;
}

// 从 7 张牌中选 5 张（C(7,5)=21 种组合），找出最优牌型等级
int eval_hand(const int cards[7]) {
    HandScore best_score;
    best_score.rank = -1;

    // 枚举所有 5 张牌的组合
    for (int a = 0; a < 3; a++) {
        for (int b = a + 1; b < 4; b++) {
            for (int c = b + 1; c < 5; c++) {
                for (int d = c + 1; d < 6; d++) {
                    for (int e = d + 1; e < 7; e++) {
                        int combo[5] = {cards[a], cards[b], cards[c], cards[d], cards[e]};
                        std::sort(combo, combo + 5,
                            [](int x, int y) { return card_rank(x) > card_rank(y); });
                        HandScore sc = eval_5cards(combo);
                        if (compare_scores(sc, best_score) > 0) {
                            best_score = sc;
                        }
                    }
                }
            }
        }
    }
    return best_score.rank;
}

// 比较两手 7 张牌，返回 >0 表示 hand_a 大
int compare_hands(const int hand_a[7], const int hand_b[7]) {
    HandScore best_a, best_b;
    best_a.rank = -1;
    best_b.rank = -1;

    // 评估 hand_a 的最优 5 张
    for (int a = 0; a < 3; a++) {
        for (int b = a + 1; b < 4; b++) {
            for (int c = b + 1; c < 5; c++) {
                for (int d = c + 1; d < 6; d++) {
                    for (int e = d + 1; e < 7; e++) {
                        int combo[5] = {hand_a[a], hand_a[b], hand_a[c], hand_a[d], hand_a[e]};
                        std::sort(combo, combo + 5,
                            [](int x, int y) { return card_rank(x) > card_rank(y); });
                        HandScore sc = eval_5cards(combo);
                        if (compare_scores(sc, best_a) > 0)
                            best_a = sc;
                    }
                }
            }
        }
    }

    // 评估 hand_b 的最优 5 张
    for (int a = 0; a < 3; a++) {
        for (int b = a + 1; b < 4; b++) {
            for (int c = b + 1; c < 5; c++) {
                for (int d = c + 1; d < 6; d++) {
                    for (int e = d + 1; e < 7; e++) {
                        int combo[5] = {hand_b[a], hand_b[b], hand_b[c], hand_b[d], hand_b[e]};
                        std::sort(combo, combo + 5,
                            [](int x, int y) { return card_rank(x) > card_rank(y); });
                        HandScore sc = eval_5cards(combo);
                        if (compare_scores(sc, best_b) > 0)
                            best_b = sc;
                    }
                }
            }
        }
    }

    return compare_scores(best_a, best_b);
}
```

**关键逻辑解释：**

1. **`eval_5cards`** — 这是核心中的核心。输入 5 张已排序的牌，判断是什么牌型。判断顺序很重要：必须从高级到低级（皇家同花顺 → 同花顺 → 四条 → ... → 高牌），否则四条会被误判为两对。

2. **顺子的特殊处理** — A-2-3-4-5 是最小的顺子（5-high straight）。此时 A 的点数是 12，但它在顺子中充当"1"的角色。代码中单独检查了这种情况。

3. **`eval_hand`** — 德州扑克用 7 张牌（2 手牌 + 5 公共牌）中最好的 5 张。代码用 5 层嵌套循环枚举 C(7,5)=21 种组合，找出最优的那个。

4. **`compare_hands`** — 对两手 7 张牌分别找最优 5 张，然后用 `compare_scores` 比较。先比牌型等级，同等级再依次比踢脚牌。

## 6. 第二步：deck.py — 牌组管理

### 为什么需要 deck.py？

游戏需要一副 52 张的扑克牌。我们需要：
1. **洗牌** — 每局开始前随机打乱
2. **发牌** — 从牌堆顶部取牌，保证同一张牌不会发两次
3. **编码转换** — Python 内部用整数（方便传给 C++），发给前端时转成 `{"suit":"♠","rank":"A"}`

### 完整代码：`server/deck.py`

```python
"""
deck.py — 牌组管理

为什么需要这个模块？
  德州扑克用一副 52 张标准扑克牌。我们需要：
  1. 洗牌（随机打乱顺序）
  2. 发牌（从牌堆顶部取牌）
  3. 在 Python 内部用整数表示牌（方便传给 C++），
     但在发送给前端时转为 {"suit":"♠","rank":"A"} 格式。

卡片编码方案（与 C++ 端完全一致）：
  card_id = rank * 4 + suit
  其中 rank: 2=0, 3=1, ..., 10=8, J=9, Q=10, K=11, A=12
       suit: ♠=0, ♥=1, ♦=2, ♣=3
  结果范围: 0 ~ 51
"""

import random

# ============================================================
# 编码映射表
# ============================================================

# 点数: 内部整数 → 前端显示字符串
RANK_MAP = {
    0: "2", 1: "3", 2: "4", 3: "5", 4: "6",
    5: "7", 6: "8", 7: "9", 8: "10",
    9: "J", 10: "Q", 11: "K", 12: "A"
}

# 花色: 内部整数 → 前端显示字符
SUIT_MAP = {
    0: "♠", 1: "♥", 2: "♦", 3: "♣"
}

# 反向映射: 前端字符串 → 内部整数
RANK_REV = {v: k for k, v in RANK_MAP.items()}
SUIT_REV = {v: k for k, v in SUIT_MAP.items()}


# ============================================================
# 编码转换函数
# ============================================================

def card_id_to_json(card_id: int) -> dict:
    """
    将内部整数编码转为前端 JSON 格式。
    例如: 50 → {"suit": "♣", "rank": "A"}
          (50 = 12*4 + 2, rank=12=A, suit=2=♣)
    """
    return {
        "suit": SUIT_MAP[card_id % 4],
        "rank": RANK_MAP[card_id // 4]
    }


def json_to_card_id(card: dict) -> int:
    """
    将前端 JSON 格式转为内部整数编码。
    例如: {"suit": "♣", "rank": "A"} → 50
    """
    return RANK_REV[card["rank"]] * 4 + SUIT_REV[card["suit"]]


# ============================================================
# Deck 类 — 牌组
# ============================================================

class Deck:
    """
    一副 52 张标准扑克牌。

    使用方式:
        deck = Deck()
        deck.shuffle()        # 洗牌
        cards = deck.deal(2)  # 发 2 张牌，返回 card_id 列表
    """

    def __init__(self):
        # cards 列表存储 0~51 的整数，列表尾部是"牌堆顶部"
        self.cards: list[int] = []

    def shuffle(self):
        """
        重置牌组为完整的 52 张牌，并随机打乱顺序。
        每次新一局开始前必须调用此方法。
        """
        self.cards = list(range(52))
        random.shuffle(self.cards)

    def deal(self, n: int) -> list[int]:
        """
        从牌堆顶部发 n 张牌。
        返回 card_id 列表，这些牌会从牌堆中移除。
        如果牌不够，会触发 IndexError（正常游戏不会发生）。
        """
        dealt = []
        for _ in range(n):
            dealt.append(self.cards.pop())
        return dealt

    def remaining(self) -> int:
        """返回牌堆中剩余的牌数"""
        return len(self.cards)
```

**关键解释：**

- **`self.cards.pop()`** — 从列表尾部弹出元素。我们约定列表尾部是"牌堆顶部"。`pop()` 既返回牌又把它从列表中移除，保证同一张牌不会发两次。
- **`card_id_to_json`** — `card_id // 4` 得到点数（整除），`card_id % 4` 得到花色（取余）。这和 C++ 端的 `card_rank()` / `card_suit()` 逻辑完全一致。
- **`RANK_REV` / `SUIT_REV`** — 反向映射表，用字典推导式从正向映射表自动生成。例如 `{"2": 0, "3": 1, ...}`。

## 7. 第三步：player.py — 玩家数据结构

### 为什么需要 player.py？

8 个玩家各有各的筹码、手牌、状态。把每个玩家的数据封装成 `Player` 类，`game.py` 就能用列表 `[Player, Player, ...]` 统一管理。

### 完整代码：`server/player.py`

```python
"""
player.py — 玩家数据结构

为什么需要这个模块？
  每个玩家有自己的筹码、手牌、当前下注额、状态等。
  把这些封装成一个 Player 类，方便 game.py 统一管理 8 个玩家。

玩家状态说明：
  - "active":  正常参与游戏，可以行动
  - "folded":  本局已弃牌，不再参与本轮
  - "out":     筹码为 0，已淘汰，不参与后续任何局
"""

from deck import card_id_to_json


class Player:
    """
    德州扑克玩家。

    属性:
        id          - 座位号 1~8
        name        - 显示名称
        chips       - 剩余筹码
        currentBet  - 当前 street 已下注总额
        hand        - 手牌（card_id 列表，0~2 张）
        action      - 最近一次动作 ("fold"/"check"/"call"/"raise"/"")
        state       - 玩家状态 ("active"/"folded"/"out")
        isCurrent   - 是否轮到该玩家行动
    """

    def __init__(self, seat: int):
        self.id = seat
        self.name = f"玩家{seat}"
        self.chips = 1000          # 初始筹码
        self.currentBet = 0        # 当局已下注金额
        self.hand: list[int] = []  # 手牌（内部 card_id）
        self.action = ""           # 最近动作
        self.state = "active"      # active / folded / out
        self.isCurrent = False     # 是否当前行动玩家

    def reset_for_new_hand(self):
        """
        每局开始前重置玩家状态。
        - 清空手牌和当前下注
        - 如果筹码为 0，标记为淘汰
        - 如果上局弃牌了，恢复为 active（筹码 > 0 时）
        """
        self.hand = []
        self.currentBet = 0
        self.action = ""
        if self.chips == 0:
            self.state = "out"
        elif self.state == "folded":
            self.state = "active"

    def to_json(self) -> dict:
        """
        将玩家状态序列化为前端需要的 JSON 格式。
        手牌从 card_id 转为 {"suit": "♠", "rank": "A"} 格式。
        """
        return {
            "id": self.id,
            "name": self.name,
            "chips": self.chips,
            "currentBet": self.currentBet,
            "hand": [card_id_to_json(c) for c in self.hand],
            "action": self.action,
            "state": self.state,
            "isCurrent": self.isCurrent,
        }
```

**关键解释：**

- **`currentBet` vs `chips`** — `currentBet` 是玩家**在本局**已经下的筹码，`chips` 是玩家**剩余**的筹码。两者之和才是玩家本局开始前的总筹码。
- **`reset_for_new_hand()`** — 每局开始前调用。注意：如果玩家上局弃牌了（`state == "folded"`），但还有筹码，要恢复为 `"active"`。
- **`to_json()`** — 手牌在内部是 `[12, 25, ...]` 这样的整数列表，发给前端前要转成 `[{"suit":"♠","rank":"A"}, ...]`。

## 8. 第四步：game.py — 游戏状态机

### 为什么这是最复杂的部分？

`game.py` 是整个后端的**大脑**。它需要：

1. 管理游戏从"等待开始"到"摊牌"的完整流程
2. 处理玩家的下注、跟注、加注、弃牌
3. 判断下注轮何时结束
4. 在摊牌时调用 C++ 库比大小
5. 分配底池给赢家

### 完整代码：`server/game.py`

```python
"""
game.py — 游戏状态机

为什么需要这个模块？
  这是整个后端的核心。它负责：
  1. 管理游戏流程：idle → preflop → flop → turn → river → showdown
  2. 处理玩家操作：fold / check / call / raise
  3. 控制下注轮：判断一圈何时结束
  4. 摊牌比牌：调用 C++ 库决定赢家
  5. 分配底池

状态机图示：
  idle ──→ preflop ──→ flop ──→ turn ──→ river ──→ showdown ──→ idle
"""

import ctypes
import os
from deck import Deck, card_id_to_json
from player import Player

# ============================================================
# 游戏常量
# ============================================================

SMALL_BLIND = 10   # 小盲注
BIG_BLIND = 20     # 大盲注

# 牌型中文名映射（与 C++ 端等级 0~9 对应）
HAND_NAMES = {
    9: "皇家同花顺", 8: "同花顺", 7: "四条", 6: "葫芦", 5: "同花",
    4: "顺子", 3: "三条", 2: "两对", 1: "一对", 0: "高牌"
}


# ============================================================
# C++ 动态库加载
# ============================================================

def _load_hand_eval_lib():
    """
    加载 C++ 编译的牌型判断动态库。
    搜索顺序：
      1. engine/build/ 目录（开发时）
      2. 与 server/ 同级的 engine/ 目录
    """
    # 获取当前文件 (game.py) 所在目录
    server_dir = os.path.dirname(os.path.abspath(__file__))
    # 尝试多个可能的路径
    candidates = [
        os.path.join(server_dir, "..", "engine", "build", "hand_eval.dll"),
        os.path.join(server_dir, "..", "engine", "build", "libhand_eval.so"),
        os.path.join(server_dir, "..", "engine", "build", "libhand_eval.dylib"),
        os.path.join(server_dir, "..", "engine", "hand_eval.dll"),
    ]
    for path in candidates:
        if os.path.exists(path):
            return ctypes.CDLL(path)
    raise FileNotFoundError(
        "找不到 hand_eval 动态库。请先编译 C++ 代码：\n"
        "  cd engine && mkdir build && cd build && cmake .. && cmake --build ."
    )

# 加载动态库
_lib = _load_hand_eval_lib()

# 配置函数签名：告诉 Python 参数和返回值类型
_lib.eval_hand.argtypes = [ctypes.POINTER(ctypes.c_int)]
_lib.eval_hand.restype = ctypes.c_int

_lib.compare_hands.argtypes = [ctypes.POINTER(ctypes.c_int), ctypes.POINTER(ctypes.c_int)]
_lib.compare_hands.restype = ctypes.c_int


def eval_hand(cards: list[int]) -> int:
    """调用 C++ eval_hand，返回牌型等级 0~9"""
    arr = (ctypes.c_int * 7)(*cards)
    return _lib.eval_hand(arr)


def compare_hands(hand_a: list[int], hand_b: list[int]) -> int:
    """调用 C++ compare_hands，>0 表示 a 大，<0 表示 b 大，=0 平分"""
    arr_a = (ctypes.c_int * 7)(*hand_a)
    arr_b = (ctypes.c_int * 7)(*hand_b)
    return _lib.compare_hands(arr_a, arr_b)


# ============================================================
# 辅助函数：找下一个 active 玩家
# ============================================================

def _next_active_index(players: list[Player], start: int) -> int:
    """
    从 start 位置开始，顺时针找下一个 state=="active" 的玩家。
    如果找不到（所有人都弃牌或出局），返回 -1。
    """
    for i in range(1, 9):
        idx = (start + i) % 8
        if players[idx].state == "active":
            return idx
    return -1


# ============================================================
# Game 类 — 游戏状态机
# ============================================================

class Game:
    """
    德州扑克游戏主控制器。

    使用方式:
        game = Game()
        result = game.process_action(player_id, "call", 0)
        state_json = game.to_json()
    """

    def __init__(self):
        # 8 个玩家，座位号 1~8
        self.players: list[Player] = [Player(i + 1) for i in range(8)]

        # 牌组
        self.deck = Deck()

        # 游戏状态
        self.phase = "idle"              # idle/preflop/flop/turn/river/showdown
        self.community_cards: list[int] = []  # 公共牌（card_id 列表）
        self.pot = 0                     # 总底池
        self.currentBet = 0              # 当前 street 要跟注的金额
        self.dealerIndex = 0             # 庄家位置 (0~7)
        self.currentPlayerIndex = -1     # 当前行动玩家索引
        self.minRaise = BIG_BLIND        # 最小加注额

        # 下注轮控制
        self._last_raiser_index = -1     # 本轮最后加注者索引
        self._acted_count = 0            # 本轮已行动人数

    # ================================================================
    # 对外入口：处理玩家操作
    # ================================================================

    def process_action(self, player_id: int, action: str, amount: int = 0) -> dict:
        """
        WebSocket 消息处理入口。
        参数:
            player_id - 玩家座位号 (1~8)
            action    - "fold" / "check" / "call" / "raise"
            amount    - 仅 raise 时需要，加注金额
        返回:
            {"ok": True}  表示操作成功
            {"error": "错误码"}  表示操作被拒绝
        """
        player = self.players[player_id - 1]

        # ── 校验 ──
        if self.phase in ("idle", "showdown"):
            return {"error": "GAME_NOT_STARTED"}
        if player.id != self.currentPlayerIndex + 1:
            return {"error": "NOT_YOUR_TURN"}
        if player.state != "active":
            return {"error": "INVALID_ACTION"}

        # ── 执行操作 ──
        if action == "fold":
            player.action = "fold"
            player.state = "folded"

        elif action == "check":
            # 让牌：只有当前轮没人下注时才能让牌
            if self.currentBet > 0:
                return {"error": "INVALID_ACTION"}
            player.action = "check"

        elif action == "call":
            # 跟注：补齐到当前最高下注额
            call_amount = self.currentBet - player.currentBet
            if call_amount > player.chips:
                call_amount = player.chips  # All-in：筹码不够就全下
            player.chips -= call_amount
            player.currentBet += call_amount
            self.pot += call_amount
            player.action = "call"

        elif action == "raise":
            # 加注：必须 >= minRaise 且 <= 玩家筹码
            if amount < self.minRaise or amount > player.chips:
                return {"error": "BELOW_MIN_RAISE"}
            player.chips -= amount
            player.currentBet += amount
            self.pot += amount
            self.currentBet = player.currentBet
            self.minRaise = amount  # 简化：新加注额就是新的 minRaise
            self._last_raiser_index = self.currentPlayerIndex
            player.action = "raise"

        else:
            return {"error": "INVALID_ACTION"}

        self._acted_count += 1
        self._next_player()
        return {"ok": True}

    # ================================================================
    # 内部方法：游戏流程控制
    # ================================================================

    def _start_new_hand(self):
        """
        开始新一局：idle → preflop
        1. 洗牌
        2. 重置所有玩家
        3. 发手牌
        4. 收盲注
        5. 设置当前玩家为大盲注下一位
        """
        # 1. 洗牌
        self.deck.shuffle()

        # 2. 重置所有玩家状态
        for p in self.players:
            p.reset_for_new_hand()

        # 3. 给每个 active 玩家发 2 张手牌
        for p in self.players:
            if p.state == "active":
                p.hand = self.deck.deal(2)

        # 4. 找小盲注和大盲注玩家
        sb_index = _next_active_index(self.players, self.dealerIndex)
        bb_index = _next_active_index(self.players, sb_index)

        # 5. 收盲注
        sb_player = self.players[sb_index]
        bb_player = self.players[bb_index]

        sb_amount = min(SMALL_BLIND, sb_player.chips)
        sb_player.chips -= sb_amount
        sb_player.currentBet = sb_amount

        bb_amount = min(BIG_BLIND, bb_player.chips)
        bb_player.chips -= bb_amount
        bb_player.currentBet = bb_amount

        # 6. 初始化游戏状态
        self.pot = sb_amount + bb_amount
        self.currentBet = bb_amount
        self.minRaise = BIG_BLIND
        self._last_raiser_index = bb_index
        self._acted_count = 0

        # 7. 当前玩家 = 大盲注下一位
        self.currentPlayerIndex = _next_active_index(self.players, bb_index)
        for p in self.players:
            p.isCurrent = False
        self.players[self.currentPlayerIndex].isCurrent = True

        self.phase = "preflop"

    def _advance_phase(self):
        """
        推进到下一阶段。
        preflop → flop → turn → river → showdown
        """
        if self.phase == "preflop":
            # 烧一张 + 发 3 张公共牌
            self.deck.deal(1)
            self.community_cards = self.deck.deal(3)
            self.phase = "flop"

        elif self.phase == "flop":
            # 烧一张 + 发 1 张公共牌
            self.deck.deal(1)
            self.community_cards += self.deck.deal(1)
            self.phase = "turn"

        elif self.phase == "turn":
            # 烧一张 + 发 1 张公共牌
            self.deck.deal(1)
            self.community_cards += self.deck.deal(1)
            self.phase = "river"

        elif self.phase == "river":
            # 进入摊牌阶段
            self.phase = "showdown"
            return  # showdown 不重置 street 状态

        # 重置 street 级别状态（flop/turn/river 共用）
        if self.phase != "showdown":
            for p in self.players:
                if p.state != "out":
                    p.currentBet = 0
                    p.action = ""
            self.currentBet = 0
            self.minRaise = BIG_BLIND
            self._last_raiser_index = -1
            self._acted_count = 0

            # 当前玩家 = 庄家下一位（小盲位置）
            self.currentPlayerIndex = _next_active_index(self.players, self.dealerIndex)
            for p in self.players:
                p.isCurrent = False
            self.players[self.currentPlayerIndex].isCurrent = True

    def _end_hand(self):
        """
        结束本局：showdown → idle
        1. 清空手牌和公共牌
        2. 淘汰筹码为 0 的玩家
        3. 轮换庄家
        """
        for p in self.players:
            p.hand = []
            p.action = ""
            p.isCurrent = False
            if p.chips == 0:
                p.state = "out"

        self.community_cards = []
        self.pot = 0
        self.currentBet = 0
        self.currentPlayerIndex = -1

        # 庄家轮换：找下一位有筹码的玩家
        self.dealerIndex = _next_active_index(self.players, self.dealerIndex)
        if self.dealerIndex == -1:
            # 所有玩家都淘汰了，重置所有人
            for p in self.players:
                p.chips = 1000
                p.state = "active"
            self.dealerIndex = 0

        self.phase = "idle"

    def _next_player(self):
        """
        移动行动权到下一位 active 玩家。
        如果下注轮结束，自动推进 phase。
        如果只剩一人未弃牌，直接跳到 showdown。
        """
        # 检查是否只剩一人
        active_players = [p for p in self.players if p.state == "active"]
        if len(active_players) == 1:
            # 唯一剩下的玩家赢得底池
            winner = active_players[0]
            winner.chips += self.pot
            self.phase = "showdown"
            return

        # 找下一位 active 玩家
        self.currentPlayerIndex = _next_active_index(self.players, self.currentPlayerIndex)

        # 更新 isCurrent 标记
        for p in self.players:
            p.isCurrent = False
        self.players[self.currentPlayerIndex].isCurrent = True

        # 判断下注轮是否结束
        if self._is_betting_round_over():
            self._advance_phase()

    def _is_betting_round_over(self) -> bool:
        """
        判断当前下注轮是否结束。

        结束条件：
        1. 只剩 ≤1 个 active 玩家
        2. 所有 active 玩家下注额相等，且：
           - 如果没人加注过（_last_raiser_index == -1），所有人都行动过
           - 如果有人加注过，行动权回到最后加注者
        """
        active_players = [p for p in self.players if p.state == "active"]

        if len(active_players) <= 1:
            return True

        # 所有 active 玩家下注额必须相等
        all_equal = all(p.currentBet == self.currentBet for p in active_players)
        if not all_equal:
            return False

        # 没人加注过 → 所有人都行动过即结束
        if self._last_raiser_index == -1:
            return self._acted_count >= len(active_players)

        # 有人加注过 → 行动权回到最后加注者
        return self.currentPlayerIndex == self._last_raiser_index

    # ================================================================
    # 摊牌比牌
    # ================================================================

    def evaluate_showdown(self) -> dict:
        """
        摊牌比牌，返回 hand_result 消息的 data 部分。
        只在 phase == "showdown" 时调用。
        """
        active_players = [p for p in self.players if p.state == "active"]

        # 情况 1：其他人全弃牌，唯一剩下的玩家自动赢
        if len(active_players) == 1:
            winner = active_players[0]
            winner.chips += self.pot
            return {
                "winners": [{
                    "playerId": winner.id,
                    "handName": "弃牌获胜",
                    "handRank": -1,
                    "winAmount": self.pot
                }],
                "players": []
            }

        # 情况 2：正常比牌
        # 对每个玩家，用 C++ eval_hand 计算牌型等级
        results = []
        for p in active_players:
            cards_7 = p.hand + self.community_cards  # 2 + 5 = 7
            rank = eval_hand(cards_7)
            results.append((p, rank))

        # 找出最高等级
        max_rank = max(r[1] for r in results)
        tied = [r[0] for r in results if r[1] == max_rank]

        # 同等级时用 compare_hands 踢脚比较
        if len(tied) > 1:
            tied = self._tiebreak(tied)

        # 分配底池（平分）
        share = self.pot // len(tied)
        remainder = self.pot - share * len(tied)
        for w in tied:
            w.chips += share
        if tied:
            tied[0].chips += remainder  # 余数给第一个赢家

        # 构建返回结果
        return {
            "winners": [
                {
                    "playerId": w.id,
                    "handName": HAND_NAMES.get(
                        next(r for p, r in results if p.id == w.id), "未知"
                    ),
                    "handRank": next(r for p, r in results if p.id == w.id),
                    "winAmount": share
                }
                for w in tied
            ],
            "players": [
                {
                    "playerId": p.id,
                    "handName": HAND_NAMES.get(r, "未知"),
                    "handRank": r
                }
                for p, r in results
            ]
        }

    def _tiebreak(self, tied_players: list[Player]) -> list[Player]:
        """
        多个玩家牌型等级相同时，用 C++ compare_hands 两两比较踢脚。
        返回最终赢家列表（可能仍有多人平分）。
        """
        winners = [tied_players[0]]
        for p in tied_players[1:]:
            cards_a = winners[0].hand + self.community_cards
            cards_b = p.hand + self.community_cards
            cmp = compare_hands(cards_a, cards_b)
            if cmp < 0:
                winners = [p]       # p 更大，替换赢家
            elif cmp == 0:
                winners.append(p)   # 平分
        return winners

    # ================================================================
    # 序列化
    # ================================================================

    def to_json(self) -> dict:
        """
        将当前游戏状态序列化为前端 game_state 消息的 data 部分。
        """
        return {
            "phase": self.phase,
            "communityCards": [card_id_to_json(c) for c in self.community_cards],
            "players": [p.to_json() for p in self.players],
            "pot": self.pot,
            "currentBet": self.currentBet,
            "dealerIndex": self.dealerIndex,
            "currentPlayerIndex": self.currentPlayerIndex,
            "minRaise": self.minRaise,
        }
```

**关键逻辑解释：**

1. **`_load_hand_eval_lib()`** — 自动搜索 C++ 编译出来的动态库。先找 `engine/build/`（CMake 编译输出），找不到就报错提示用户先编译。

2. **`ctypes` 配置** — `argtypes` 告诉 Python "这个 C 函数接受什么参数"，`restype` 告诉 Python "返回什么类型"。不配置的话，Python 可能传错数据类型导致崩溃。

3. **`process_action`** — 这是前端调用的唯一入口。先做三层校验（游戏是否开始？是否轮到你？你是否还活着？），再执行具体操作。

4. **`_is_betting_round_over`** — 下注轮结束的判断是德州扑克最容易出 bug 的地方。核心逻辑：所有人下注额相等 + 行动权回到最后加注者（或所有人都行动过）。

5. **`_tiebreak`** — 当两个玩家都是"两对"时，需要比"大对→小对→踢脚"。这个逻辑在 C++ 的 `compare_hands` 中实现，Python 只负责调用。

6. **All-in 处理** — 当玩家筹码不够跟注时，自动全下（`call_amount = player.chips`）。后续下注会形成边池（side pot），但本教程简化处理，不实现边池。

## 9. 第五步：main.py — WebSocket 服务入口

### 为什么需要 main.py？

这是整个后端的**启动入口**。它：
1. 启动 WebSocket 服务器，监听 `ws://127.0.0.1:9001`
2. 接收前端发来的 JSON 消息（`join`、`start_game`、`player_action`）
3. 调用 `game.py` 处理逻辑
4. 把结果广播给所有连接的前端

### 完整代码：`server/main.py`

```python
"""
main.py — WebSocket 服务入口

为什么需要这个文件？
  这是整个后端的启动入口。它负责：
  1. 启动 WebSocket 服务器，监听 ws://127.0.0.1:9001
  2. 接收前端发来的 JSON 消息
  3. 调用 game.py 处理游戏逻辑
  4. 把游戏状态广播给所有连接的前端

启动方式：
  python main.py
  然后前端连接 ws://127.0.0.1:9001
"""

import asyncio
import json
from websockets.asyncio.server import serve
from game import Game

# ============================================================
# 全局状态
# ============================================================

# 游戏实例（全局唯一）
game = Game()

# 连接管理：player_id → websocket
# 为什么用字典？因为需要根据玩家 ID 找到对应的 WebSocket 连接来发送消息
connections: dict[int, any] = {}


# ============================================================
# 广播函数
# ============================================================

async def broadcast_game_state():
    """
    向所有连接的客户端广播当前游戏状态。
    每次游戏状态变化后（有人下注、阶段切换等）都要调用。
    """
    msg = json.dumps({
        "type": "game_state",
        "data": game.to_json()
    })
    # 并发发送给所有客户端
    tasks = [ws.send(msg) for ws in connections.values()]
    await asyncio.gather(*tasks)


async def broadcast_hand_result(result: dict):
    """
    向所有客户端广播摊牌结果。
    """
    msg = json.dumps({
        "type": "hand_result",
        "data": result
    })
    tasks = [ws.send(msg) for ws in connections.values()]
    await asyncio.gather(*tasks)


async def send_error(websocket, code: str, message: str):
    """
    向单个客户端发送错误消息。
    """
    await websocket.send(json.dumps({
        "type": "error",
        "data": {"code": code, "message": message}
    }))


# ============================================================
# WebSocket 消息处理
# ============================================================

async def handler(websocket):
    """
    每个 WebSocket 连接对应一个 handler 协程。
    当有新的前端连接时，这个函数被调用。
    """
    player_id = None  # 当前连接对应的玩家 ID

    try:
        # async for 循环：持续接收消息，直到连接断开
        async for raw in websocket:
            try:
                msg = json.loads(raw)
            except json.JSONDecodeError:
                await send_error(websocket, "INVALID_JSON", "消息格式错误")
                continue

            msg_type = msg.get("type", "")

            # ── join：玩家加入 ──
            if msg_type == "join":
                seat = msg.get("data", {}).get("seat", 0)
                if not 1 <= seat <= 8:
                    await send_error(websocket, "INVALID_SEAT", "座位号必须在 1~8 之间")
                    continue
                player_id = seat
                connections[player_id] = websocket
                print(f"[INFO] 玩家{seat} 已加入 (seat={seat})")
                await websocket.send(json.dumps({
                    "type": "info",
                    "data": {"message": f"玩家{seat} 已加入，等待开始游戏"}
                }))

            # ── start_game：开始游戏 ──
            elif msg_type == "start_game":
                if game.phase != "idle":
                    await send_error(websocket, "GAME_ALREADY_STARTED", "游戏已在进行中")
                    continue
                active_count = sum(1 for p in game.players if p.state != "out")
                if active_count < 2:
                    await send_error(websocket, "NOT_ENOUGH_PLAYERS", "至少需要 2 名玩家")
                    continue
                print("[INFO] 游戏开始")
                game._start_new_hand()
                await broadcast_game_state()

            # ── player_action：玩家操作 ──
            elif msg_type == "player_action":
                if player_id is None:
                    await send_error(websocket, "NOT_JOINED", "请先加入游戏")
                    continue
                data = msg.get("data", {})
                action = data.get("action", "")
                amount = data.get("amount", 0)

                result = game.process_action(player_id, action, amount)
                if "error" in result:
                    await send_error(websocket, result["error"], result["error"])
                else:
                    print(f"[INFO] 玩家{player_id}: {action} {amount if action == 'raise' else ''}")
                    await broadcast_game_state()

                    # 如果进入 showdown，自动比牌
                    if game.phase == "showdown":
                        hand_result = game.evaluate_showdown()
                        await broadcast_hand_result(hand_result)
                        # 3 秒后自动开始下一局
                        await asyncio.sleep(3)
                        game._end_hand()
                        await broadcast_game_state()

            else:
                await send_error(websocket, "UNKNOWN_TYPE", f"未知消息类型: {msg_type}")

    except Exception as e:
        print(f"[ERROR] 连接异常: {e}")
    finally:
        # 连接断开时的清理
        if player_id and player_id in connections:
            del connections[player_id]
            print(f"[INFO] 玩家{player_id} 断开连接")


# ============================================================
# 启动服务
# ============================================================

async def main():
    """
    启动 WebSocket 服务器。
    """
    print("=" * 50)
    print("  德州扑克后端服务")
    print(f"  监听地址: ws://127.0.0.1:9001")
    print("  等待前端连接...")
    print("=" * 50)

    # serve() 创建一个 WebSocket 服务器
    # handler 是每个连接的处理函数
    async with serve(handler, "127.0.0.1", 9001):
        # create_future() 创建一个永远不会完成的 Future
        # 这样服务器就会一直运行，不会退出
        await asyncio.get_running_loop().create_future()


if __name__ == "__main__":
    asyncio.run(main())
```

**关键解释：**

- **`asyncio`** — Python 的异步编程库。WebSocket 服务器需要同时处理多个连接，用异步可以避免"一个玩家卡住所有人"。
- **`serve(handler, "127.0.0.1", 9001)`** — 在本地 9001 端口启动 WebSocket 服务。`127.0.0.1` 表示只接受本机连接（安全）。
- **`broadcast_game_state()`** — 用 `asyncio.gather` 并发发送给所有客户端，比逐个发送快。
- **`connections` 字典** — key 是玩家 ID（1~8），value 是 WebSocket 连接对象。这样可以根据玩家 ID 找到对应连接。
- **showdown 自动流程** — 当 `game.phase == "showdown"` 时，自动调用 `evaluate_showdown()` 比牌，广播结果，等 3 秒后自动开始下一局。

## 10. Python 调用 C++ 动态库详解

### 10.1 整体流程

```
Python (game.py)
    │
    │  ctypes.CDLL("hand_eval.dll")
    ▼
C++ 动态库 (hand_eval.dll)
    │
    │  extern "C" 导出
    ▼
eval_hand() / compare_hands()
```

### 10.2 关键代码逐行解释

```python
import ctypes

# 第 1 步：加载动态库
# Windows: hand_eval.dll
# Linux:   libhand_eval.so
# macOS:   libhand_eval.dylib
lib = ctypes.CDLL("engine/build/hand_eval.dll")

# 第 2 步：告诉 Python 函数签名
# argtypes: 参数类型列表
# restype:  返回值类型
lib.eval_hand.argtypes = [ctypes.POINTER(ctypes.c_int)]
lib.eval_hand.restype = ctypes.c_int

# 第 3 步：准备数据
# C++ 期望 int cards[7]，Python 用 ctypes 数组模拟
cards = [48, 33, 3, 16, 25, 40, 8]  # 7 张牌的 card_id
arr = (ctypes.c_int * 7)(*cards)     # 创建 C 风格数组

# 第 4 步：调用
rank = lib.eval_hand(arr)
print(f"牌型等级: {rank}")  # 0~9
```

### 10.3 为什么需要 `argtypes` 和 `restype`？

如果不设置：
- Python 可能把整数当成任意精度的大整数传给 C++，导致内存错误
- Python 不知道返回值是 `int`，可能返回一个 `c_int` 对象而不是 Python `int`

设置后，`ctypes` 会自动做类型转换。

### 10.4 `(ctypes.c_int * 7)(*cards)` 是什么？

- `ctypes.c_int * 7` — 定义一个"7 个 int"的 C 数组类型
- `(*cards)` — 把 Python 列表解包，作为数组的初始值

等价于 C++ 中的：
```cpp
int arr[7] = {48, 33, 3, 16, 25, 40, 8};
```

## 12. 常见错误与解决办法

### 12.1 `FileNotFoundError: 找不到 hand_eval 动态库`

**原因：** C++ 库还没编译，或者编译产物不在预期路径。

**解决：**
```bash
cd engine
mkdir build && cd build
cmake ..
cmake --build .
```
确认 `engine/build/` 下生成了 `hand_eval.dll`（Windows）或 `libhand_eval.so`（Linux）。

### 12.2 `ImportError: No module named 'websockets'`

**原因：** 没安装 `websockets` 库。

**解决：**
```bash
pip install websockets
```

### 12.3 `OSError: [WinError 193] %1 is not a valid Win32 application`

**原因：** Python 是 64 位的，但 C++ 库编译成了 32 位（或反过来）。

**解决：** 确保 Python 和 C++ 编译器都是同一架构（都用 64 位）。用 MinGW-w64 时选 `mingw-w64-x86_64-gcc`。

### 12.4 `AttributeError: function 'eval_hand' not found`

**原因：** C++ 函数没有用 `extern "C"` 导出，导致函数名被 C++ 编译器"修饰"了。

**解决：** 确保 `hand_eval.h` 中的函数声明在 `extern "C" { ... }` 块内，且 `bind.cpp` 包含了 `hand_eval.h`。

### 12.5 游戏卡住不动，没人能操作

**原因：** 下注轮结束判断逻辑有 bug，最常见的是 `_is_betting_round_over()` 条件不满足。

**排查：**
1. 在 `_next_player()` 中加 `print(f"active: {len(active_players)}, acted: {self._acted_count}, last_raiser: {self._last_raiser_index}")`
2. 检查是否所有 active 玩家的 `currentBet` 都等于 `self.currentBet`
3. 检查 `_last_raiser_index` 是否正确更新

### 12.6 牌型判断结果不对

**原因：** Python 和 C++ 的卡片编码不一致。

**排查：**
1. 在 Python 端打印 `card_id`，在 C++ 端打印 `card_rank()` 和 `card_suit()`
2. 确认两边的编码公式都是 `rank * 4 + suit`
3. 确认 rank 和 suit 的映射表完全一致

### 12.7 `websockets` 版本兼容问题

**原因：** `websockets` 库在 11.0 版本后 API 有变化。

**解决：** 本教程使用 `websockets>=12.0` 的 API。如果遇到 `serve` 导入错误，检查版本：
```bash
pip show websockets
```
如果版本低于 12.0，升级：
```bash
pip install --upgrade websockets
```

### 12.8 多个浏览器标签页连接同一座位

**原因：** `connections` 字典用座位号做 key，后连接的会覆盖先连接的。

**解决：** 这是设计如此——一个座位只能有一个连接。如果需要支持观战，可以额外维护一个观战者列表。

## 附录 B：消息类型速查表

| 消息类型 | 方向 | 说明 |
|----------|------|------|
| `join` | 客户端→服务端 | 玩家加入，需指定 `seat` (1~8) |
| `start_game` | 客户端→服务端 | 开始新一局 |
| `player_action` | 客户端→服务端 | 玩家操作，含 `action` 和 `amount` |
| `game_state` | 服务端→客户端 | 游戏状态推送 |
| `hand_result` | 服务端→客户端 | 摊牌结果 |
| `error` | 服务端→客户端 | 错误提示 |
| `info` | 服务端→客户端 | 一般信息提示 |

## 附录 C：错误码清单

| 错误码 | 含义 |
|--------|------|
| `INVALID_JSON` | 消息不是合法的 JSON 格式 |
| `INVALID_SEAT` | 座位号不在 1~8 范围内 |
| `NOT_JOINED` | 还没加入游戏就发送了操作 |
| `GAME_NOT_STARTED` | 游戏还没开始（phase 为 idle 或 showdown） |
| `GAME_ALREADY_STARTED` | 游戏已在进行中，不能重复开始 |
| `NOT_ENOUGH_PLAYERS` | 活跃玩家不足 2 人 |
| `NOT_YOUR_TURN` | 还没轮到你行动 |
| `INVALID_ACTION` | 操作不合法（如 check 时有人下注） |
| `BELOW_MIN_RAISE` | 加注金额低于最小加注额 |
| `UNKNOWN_TYPE` | 未知的消息类型 |
